# 溶媒和特徴を別のカーネルに分けた比較

2026-10-13、[ALPB特徴を既存物理ブロックへ追加した比較](alpb-feature-comparison.md)に続き、
同じ8特徴を独立した距離として扱う方式を学習しました。学習系列内のδDは改善しましたが、
δPとδHは悪化しました。固定した全3成分の採用条件を満たさず、基準モデルを保持しました。
HSPの独立実測教師、高分子・界面活性剤の適用資格は増えていません。

## 一つだけ変えた構造

化学105特徴の線形カーネル、固定MoLFormer全768次元のRBF、既存物理24列または
QM9推定6列を加えた30列のRBF、ALPB8列のRBFを加算しました。
重みは順に0.4／0.4／0.15／0.05と固定し、重みの探索はしていません。
ALPBの中央値・欠損マスク・尺度は各学習部分だけから求めます。
その学習部分で全欠損のブロックは無効のまま、残りの重みを再配分しません。

既存の化学・Embedding・物理特徴の前処理、直接δの二乗損失を使うsoftplus応答、
一度だけの初期化、最適化の拒否条件は保持しました。新しい保存形式では4項の構造を
明示し、既存3項の予測器と区別します。新しい配座、量子計算、外部重み、補助教師は追加しません。

757行・402系列の公開参照HSP、元の外側5分割・内側5分割、13候補を保持しました。
基準方式の外側検証予測と最終モデルは、ハッシュで固定した前回の保存物を比較専用に再利用しました。
基準モデルの予測を正解値や擬似ラベルへ変えていません。変更した方式だけを外側で学習し、
全成分の外側検証系列平均MSEが基準の0.99倍以下になった場合だけ採用する計画でした。
数値失敗を除外する既存の候補規則、選択した最終学習の失敗で停止する規則も保持しました。

## 学習側で決めた結果

元のδのMSE、単位はMPaです。外側の検証系列を等しく重み付けした値で、
外部1,013行のMSEとは別の指標です。

| 成分 | 基準方式 | 8列を物理ブロックへ追加 | 独立したALPBカーネル |
| --- | ---: | ---: | ---: |
| δD | 0.317243 | 0.313401 | 0.313098 |
| δP | 2.600983 | 2.637616 | 2.621147 |
| δH | 1.281181 | 1.277337 | 1.285317 |

独立したALPBカーネルではδDが約1.31%改善し、δPは約0.78%、δHは約0.32%悪化しました。
採用判定はδDのみ通過しました。全成分での条件を満たさず、変更方式の最終全件学習は行いませんでした。
基準方式の選択[12, 6, 12]を保持し、採用モデルのALPB使用記録はFalseです。
全1,770行の予測と、方式・出典・分割・欠損処理を保存してから学習処理を終了しました。

保存モデルの独立数値照合と、新しく固定した予測による参照評価は、この文書作成時点では未完了です。
前回の基準方式の参照成績を、新方式の精度向上として使いません。

## 確認した範囲と未達の資格

自作配列と独立した距離計算で4項のカーネルを確認しました。学習部分の外の特徴・教師を
書き換えても、その部分の前処理・候補選択は変わりません。全欠損のALPBを推論側の値で
有効にしないこと、保存形式の改変拒否、再読込み、採用しなかった場合の基準モデルへの経路、
失敗診断の保存を確認しました。これらは計算と分割の確認であり、物理精度の検証ではありません。

HSP教師は測定系譜・状態・温度が不明な`published_reference`757行のままで、
新しい独立実測HSPは0行です。ALPBの項は計算した特徴で、実測の水素結合強度やδP／δHではありません。
露出済みExcelは評価専用のまま、学習・特徴量・設定選択・校正に使っていません。
高分子、EO/PO界面活性剤、イオン性分子、混合物の通常推算拒否を維持しています。

外部資産は`audit_basis="operator_assumption"`の科学研究・私用・非商用に限定し、
パラメータの独立した許諾は未知のまま保持します。元データ、特徴配列、分子別予測、学習済み重みは公開しません。
校正した不確実性、未知系列への性能、実測による物理精度・材料適用資格は未達です。
