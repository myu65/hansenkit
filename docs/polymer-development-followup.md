# ポリマーと活性剤の追加検証

目的は、構造から役に立つ推算を得ることです。現在の参照比較だけでは、
高分子・活性剤のHSP3成分の実用精度を確認できていません。
この記録では構造モデルの追加比較と、学習へ加える前の原資料確認を分けます。
外部データ・係数・重み・画像・軌道は公開リポジトリへ含めません。

## 溶媒の基準値と構造補正

[最初のPolySol比較](polymer-compatibility.md)では、独自19特徴と固定MoLFormerの回帰が、
溶媒カテゴリー別の訓練割合を上回りませんでした。同じ訓練73観測・26系列だけの診断でも、
カテゴリー対照のOOF loglossは0.442503、A/Bの選択時の値は0.641089／0.687426でした。
対照の系列・材料ペア・反復の重み付けは、独立した不均等系列の自作検証と一致しました。

追加実験は、カテゴリーの基準logitを固定し、構造から補正を学習する二値回帰です。
候補は対照のみ、19特徴の補正、固定768次元表現の補正で、後二者のalphaは0.1／1／10です。
元の訓練系列5分割を外側に使い、各訓練部分の中で選択をやり直します。
補正の基準値も、その補正モデルの訓練部分だけで系列を外して作り直します。
元の二値正解と交差エントロピーを使い、0/1をlogitへ変換した擬似ラベルは作りません。

全190行の既存の正解を含まない特徴キャッシュは対応確認に読めますが、
前処理・基準値・選択・補正の学習には元の適用可能な訓練73行だけを渡します。
校正・テストの正解や既存モデルの予測は、その学習操作へ渡しません。
元の系列予約と分割を保持し、足りないカテゴリーや数値収束を満たさない候補は理由付きで拒否します。
既存の保留評価を再利用する場合は探索的な参照比較と記録し、新しい独立実測とは呼びません。

実際に比較を実行し、全190行の元状態を保持したまま訓練73行でモデルとOOFを保存しました。
全訓練を使う最終選択では、7候補すべての5分割評価が成立しましたが、対照のみが選ばれました。
下表は訓練系列内の選択指標です。小さいほど良く、未知材料の実測精度ではありません。

選択をさらに外側の元5分割で調べると、各外側訓練部分の内側で、補正の基準値を作る
追加の系列分割がカテゴリー当たり2系列を満たせませんでした。
各候補の不適用分割数は外側ごとに3／4／2／1／5、
6構造候補で計90件の同じ系列数不足を保存しました。全5外側分割で対照が選ばれ、
選択手順全体のOOFもlogloss 0.442503、Brier 0.136195で対照と一致しました。
しきい値を緩めたり、都合の良いカテゴリーへ分割し直したりしていません。

今回も構造補正の利点を示せませんでした。最終モデルは約4.2 kBのカテゴリー基準値で、
構造補正を使いません。旧A/Bモデルを置き換えず、保留テスト・校正用正解の再読や再評価は0です。
新しい学習データ、特徴列、alpha、外部エンコーダの実行も加えていません。
自作配列13テスト、runner7テスト、独立した配列・runner検証を通してから実行しました。
実行後の独立NumPy照合では、保存した5外側モデルによる全73行のlogitがOOFと完全一致し、
元の系列対応から90件の系列数不足も再集計しました。正解・特徴値を読み直した精度検証ではありません。

## 適用範囲を広げるために残る確認

構造、鎖長、末端、分布、測定条件が対応する新しい系列で、構造モデルが対照より良いかを調べます。
追加MDは元の鎖・力場・条件・独立反復を保った延長中です。時系列の診断通過と、
実物の物理精度、HSP3成分の分離はそれぞれ確認が必要です。
既知資料の照合、有限計算、補助学習の件数だけで通常のHSP拒否を解除しません。

ローカル実験は`audit_basis="operator_assumption"`、科学研究・私用・非商用に限定します。
SI、データ記録、上流の表、依存コード・重みの利用条件は別々に保持します。
