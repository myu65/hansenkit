# 実験由来の不飽和ポリエステルHSPと原料組成の探索

新しく取得した一次論文の21材料で、原料組成による回帰とMnなどを加えた回帰を比較しました。
これは材料の原料処方を入力にした小規模な探索で、SMILESからのHSP推算の検証ではありません。
同じ骨格原料を使う試料をまとめた11系列の分割では、Mnなどの追加で誤差が小さくなりました。
フタル酸系19材料を一群として外す3系列の分割では、全成分のR²が負でした。
独立実測1,000化合物の非劣性や、高分子の物理推算バックエンドの達成とは扱いません。

## 出典と材料の資格

[Molina et al., 2019](https://doi.org/10.3389/fchem.2019.00375)の原試験に由来する資料です。
21材料の組成・Mn・分散度とHSPを、Tables 1/2の同じ材料番号で照合しました。
原試験は100 mg/mL、40溶媒、24時間の溶解観察で、HSPiPによる球フィットです。
これは実験から導いた球の中心であり、構造予測の教師値や3種の凝集エネルギーの直接測定とは区別します。
論文の溶媒参照値と球フィットの規約も方法の一部です。

取得したPMC6545879のXMLは184,410 bytes、SHA-256は
`bf9f21244fda38cd1ccdea29835d23c8283843b44339d59a24d144aba529db10`。
XMLはCC BYを宣言していますが、このlicenseノードには版番号・URLがありません。
正確な21材料と固定した実験だけを、ユーザーの監査通過仮定によるローカル許可に記録しました。
原資料、数値表、特徴・予測配列、学習済みヘッドはGitに含めません。
元の取得台帳は準備専用のまま残し、固定計画の許可で上書きしません。

数値のHSP試験温度は未指定です。合成の200°C、SECの30°C、粘度測定の23°Cを
HSPの温度に代用せず、`room temperature`と`temperature_k=null`を保持します。
Mnはポリスチレン標準に対するSEC値で950–2,678 g/mol、分散度は1.50–3.90です。
原料の仕込み比から実際の共重合配列・組成、E/Z比、末端分布を決められません。
DPGの位置異性体、CHDMのcis/trans、単官能停止剤の百分率の分母も未確定です。
実際の分子グラフを作れないため、MoLFormerの入力と通常の`PolymerInput`へ変換しません。

## 固定した分割と学習

計画SHA-256: `212f5d56a83075696ba0628a23d1db6e5c1a07f4bbf9a55cad9f69cd2ef92bab`。
出典の値を既に読んだ集団なので、盲検評価とは呼びません。
テスト誤差による設定変更・試料除外・値の修正は行っていません。

- 原料処方11特徴: 4グリコールの仕込み割合、4酸群の割合、2停止剤の有無、初期の酸/OH官能基比。
  AM/AFは粗い不飽和酸群にまとめ、実際のE/Z比を推定しません。
  分母未確定の停止剤は割合でなく有無だけを使います。
- メタデータ4特徴: log(Mn)、1,000/Mn、log(分散度)、記載された合成終点の酸価。
  純粋に構造だけを入力した回帰ではありません。
- 除外特徴: Tg、HSPの合計値・球半径、元のQSPR/GC係数、Excelの値・係数、
  HSPから導いた粘度表のREDなど。HSPiT/MathieuのExcelは開かず、原料特徴にも使いません。
- Ridge alpha 100、SVD、各学習系列の合計重みを等しくします。
  標準化、平均値、回帰、OODの参照範囲は各分割の学習群だけから求めます。
- 11系列: グリコールと酸の原料支持集合でまとめ、割合・Mn・停止剤の違いを同じ系列に保ちます。
  同じ組成でMnが違う材料3/16/17も同じ系列です。各系列を一度ずつ外します。
- 強い3系列: フタル酸を含む全19件を同じ群にします。残る2群は各1件です。
  19件を評価する分割の学習は2件だけです。両分割を事前に固定し、良い方を選びません。

既知の処方系列の分割間重複は0ですが、未知の実際の分子グラフや既存Excelとの材料同一性を
完全に証明したわけではありません。この実験を過去の分子・MDモデルへ結合せず、
既存のExcel予約と学習・予測は保持しました。独立した材料確認・予約と再学習なしに転用しません。

## 結果と外挿

単位はMPa^0.5。各材料を一度だけ評価した21件の結果です。

| 分割 | 回帰 | δD MAE / RMSE / R² | δP MAE / RMSE / R² | δH MAE / RMSE / R² |
| --- | --- | --- | --- | --- |
| 11系列 | 原料処方 | 0.718 / 0.883 / -0.488 | 2.308 / 2.469 / -0.062 | 1.265 / 1.451 / -0.032 |
| 11系列 | 原料＋メタデータ | 0.664 / 0.807 / -0.243 | 2.149 / 2.330 / 0.053 | 1.189 / 1.329 / 0.134 |
| 11系列 | 学習系列の重み付き平均 | 0.669 / 0.774 / -0.142 | 2.636 / 2.832 / -0.398 | 1.402 / 1.596 / -0.250 |
| 強い3系列 | 原料処方 | 0.976 / 1.161 / -1.572 | 2.504 / 2.722 / -0.292 | 1.859 / 2.025 / -1.010 |
| 強い3系列 | 原料＋メタデータ | 0.957 / 1.138 / -1.467 | 2.394 / 2.602 / -0.181 | 1.768 / 1.927 / -0.821 |
| 強い3系列 | 学習系列の重み付き平均 | 0.886 / 1.066 / -1.166 | 2.595 / 2.754 / -0.322 | 1.871 / 2.034 / -1.028 |

11系列でMnなどを加えると、原料のみのMAEよりD/P/Hが7.6%/6.9%/6.1%小さくなりました。
強い3系列でも2.0%/4.4%/4.9%小さくなりましたが、全成分のR²が負です。
両分割で、δDは学習系列の平均よりRMSEが大きく、誤差改善は確立していません。
これは原論文の全試料で学習したQSPR係数や、既存GC手法との非劣性比較ではありません。

学習特徴の最小・最大から外れる材料は、11系列で原料のみ11件、メタデータ追加12件。
強い3系列では両方式とも21件すべてが範囲外でした。全予測は有限で、負値は0です。
これだけで物理推算の適用資格にはなりません。独立校正群はなく、校正済み区間や
3群のブートストラップから精度保証を出しません。B/Cもこの未確定の構造表現には実施しません。

## 原資料の不一致と検証

合計HSPと3成分のノルムを、各記載値の丸め区間で照合しました。
材料2の合計値は区間が重ならず、元の値を保持してフラグを付けました。除外はしていません。
本文の15材料と表の21材料、PA/AP略号、DPGのみと説明される材料4と
表の組成の違いも保持しています。後者は表では材料14がDPGのみです。

酸価とPS相対Mnから計算した平均鎖当たりの酸当量は0.508–1.676です。
これは未反応酸やMn校正の影響を含み、末端数の確定には使えません。
単に「アルコール末端」として2つのOHでキャップすると、元の材料を代表できません。

独立プロセスでXMLから21材料を抽出し直し、特徴・系列・全数値と丸め不一致を照合しました。
28個の保存ヘッドを読み戻し、sklearnを使わない重み付きNumPyの正規方程式で再計算しました。
全予測・MAE/RMSE/R²・系列平均MAE・負値・OODが一致し、最大予測差は7.11×10⁻¹⁵でした。
初回準備で0.90とfloatの文字列0.9の違いを不正とした失敗も保存しました。
数値を変えず字句検証を修正し、新しいv2計画を固定してから学習しています。

次は数値の試験温度、実際の取り込み組成、末端・異性体、元の溶解判定と球フィットの
不確かさを確認できる資料を増やします。独立測定の分子HSP1,000件と、
高分子・長鎖界面活性剤の検証済み推算は引き続き必要です。
