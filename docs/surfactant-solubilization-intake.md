# 活性剤の可溶化原表を、条件付きの測定候補として整理する

2026-10-14、[#108](https://github.com/myu65/hansenkit/issues/108)で
[PLOS ONEの一次研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0249485)の
Table 1を取得・照合しました。記事はCC BY 4.0です。
対象はsimvastatinの可溶化で、HSP3成分の測定ではありません。
原表の数値、画像、候補台帳とレビューはローカルに保持し、Gitや配布物へ含めません。

## 実際の原表で確かめた点

| 項目 | 結果 |
| --- | --- |
| 原報の測定値 | 水3点、6種類の活性剤の72点、計75点 |
| 活性剤 | Tween20/80、Myrj52/59、Brij35/58の原報grade |
| 条件 | 3温度・4濃度。温度とmMの原表記を保持 |
| 同じ表の計算値 | 理想溶解度3点を測定候補から除外 |
| 不確かさ | 脚注の相対不確かさ。各セルのSDは未報告 |
| HSPiP値 | 別のTable 2は取得・採用しない |

原表は25測定行と3温度列からなります。最後の理想溶解度行を教師へ使いません。
75点は1種類の薬物と6種類の原報gradeに対応し、独立した75化合物には数えません。
三反復という方法記載から、セルごとのSDや信頼区間を作りません。
元の有効桁と指数を残し、単位換算、平均化、補間、重複の削除も行っていません。

公式のTable 1専用PNGだけを116,846 bytesで取得しました。SHA-256は
`36aff6c45407207b768cb19adb91f4d9029e8379b469d0d6bce3ab4b0222e469`です。
発行元のサイズ・型・不透明なETagと照合しましたが、ETagをMD5とみなしていません。
発行元の暗号学的ハッシュは提供されておらず、ローカルの内容指紋を記録したものです。

## 小さいローカル処理で全件を確認

画像の取得許可と、候補の転記・準備許可を別に記録しました。
使用範囲は`operator_assumption`による科学研究・私用・非商用で、学習と再配布は無効です。
原画像とレビュー、二つの転記、処理コードのハッシュを検査してから転記を読み込みました。
別担当は先に独立した75セルの転記を封印し、全セル・見出し・脚注・除外行が一致しました。

既存の公開APIは二値・カテゴリの観測用なので、変更していません。
この定量候補は、原表の行列位置と条件を持つ別のローカル台帳です。
相対不確かさは原文のまま保存し、統計上の詳しい定義を確認した値にはしていません。
全台帳の保存復元と75件の完全一致検索が通過しました。
未測定温度と未知gradeの2照会は0件で、数値の補完はありません。
4件の自作試験で、欠落・重複・計算行・不正値を含む原表全体の拒否と、原文・不確かさの保持を確認しました。

コード確認では、初版のPython実行が未確認のキャッシュを使う余地を見つけました。
初版を保存したまま、検査したコード本文を直接実行する修正版を追加しました。
別担当の自作ケースでも、キャッシュを使わず改変コードを実行前に拒否することを確認しています。
修正版の75点の台帳は、初版と内容指紋まで一致しました。二つの実行を150点へ足していません。

## 学習前に残る確認

EO分布、lot、純度、Mn/Mw、末端、試料ごとの相を確認できていません。
原報のモル分率の定義を水・活性剤混合物へどう適用したか、統計的な不確かさの詳しい定義も未確認です。
72時間という原報の手順だけで、平衡到達を新たに確認したとは扱いません。
記事本文の測定・分離・分析温度は別々に保持し、同じ温度へ置き換えません。

既存HSP予約5,176別名とその指紋を保持しました。
今回のgrade名だけでは構造や全材料系列を正規化できず、新しい系列照合や分離証明は作っていません。
`global_isolation_certificate_qualified=False`、学習・物理精度・HSP適用のフラグもfalseです。
追加HSP教師0件、追加量子教師0件、モデル学習0件です。

次の学習には、元の測定定義と材料の対応を確認した別の計画が必要です。
薬物・媒体・材料の予約と系列分割を先に固定し、元の観測数と不明点を保持します。
この可溶化候補を通常の高分子・活性剤・混合物HSP推算へ転用しません。
