# 50構造への参照HSP学習の拡張

2026-10-11、学習を18構造から50構造・51参照行・40系列へ増やし、4方式を実行しました。
δHの誤差は一部で下がりましたが、δD・δPは悪化しました。
従来の1,013構造に対する全3成分の非劣性は、全方式で未達です。
追加値の測定系譜は不明で、`published_reference`のローカル研究です。
独立実測の教師件数や、実用精度を確認した実験として数えません。

不一致3行と未照合の候補は入れず、元のSMILESを別の構造へ置き換えていません。
ネットワークで取得できた部分集合に偏りがあり、全候補を代表する抽出とは主張しません。

新しい32構造は、全評価予約1,266構造・132骨格・2,798別名と重なりません。
旧Murcko、保守的なcore、完全な範囲内の互変異性体の予約を保持しました。
元18件は以前の限定許可と出典を保持し、追加32構造も含めて全学習群と1,013評価構造の
同一性・系列別名の重なりが0であることを確認しました。
同じ構造を持つ追加2行を平均や削除で統合せず、同じ学習系列に残しました。

取得時の学習禁止フラグは変更していません。別の正確な部分集合レビューで、
ユーザーの監査通過の仮定を`audit_basis="operator_assumption"`として記録しました。
科学研究・私用・非商用のローカル学習とモデル状態の保存だけが対象です。
原表・生データ・構造/特徴/予測配列・学習済み重みはGitに追加していません。
この仮定で元表の権利や測定系譜を確定したとは扱いません。
HSPiT Excelの値・係数、既存モデルの予測値や参照GCの出力は学習入力にしていません。

## 学習と評価の条件

Aは105化学特徴、Bは確認済みMoLFormer公開10%版の固定768次元表現、
A＋QM9は6つの推定量子特徴を追加します。既存のCPU特徴をハッシュで検証し、
追加構造を同じ確認済みCPUエンコーダ・4スレッド・batch size 16で処理しました。
自動ダウンロード、未知トークンの補填、SMILESの切捨ては行いません。
補助QM9の61,622分子はHSP正解51行に足して数えません。

正則化候補、平均値の候補、seed 42、系列を等しく扱うMAEは
[従来の学習内選択](train-only-selection.md)から維持しています。
スケーラー・回帰・OODの特徴範囲は学習行だけから求めます。
温度・試料状態は未知のまま保持し、298.15 Kの値と偽って通常のCLIへ読み込みません。

Cは5つの外側系列分割で残差の強さを選び、その各学習群内の4分割で残差目標を作ります。
基礎回帰の選択も、それぞれの学習部分集合の中だけで繰り返します。
外側の検証ラベルが、基礎回帰の設定選択や学習残差へ入りません。
以前の18件では系列を一つずつ外したため、Cはデータ数と分割方式の両方が変わっています。
Cの差をデータ追加だけの効果として解釈しません。
全モデルと全予測を固定してから、以前から探索した1,013構造・68系列の参照値を読みました。
これは新しい盲検や独立実測テストではありません。

## 結果

単位はMPa^0.5。MAE / RMSE / R²を全1,013構造で報告します。

| 方式 | δD | δP | δH |
| --- | --- | --- | --- |
| A 化学特徴 | 1.642 / 2.049 / -0.393 | 4.013 / 5.305 / -0.557 | 2.774 / 4.115 / 0.295 |
| B 固定MoLFormer | 2.017 / 2.506 / -1.082 | 4.293 / 5.541 / -0.699 | 3.733 / 5.212 / -0.130 |
| C 残差ハイブリッド | 1.642 / 2.049 / -0.393 | 4.251 / 5.602 / -0.736 | 2.808 / 4.164 / 0.278 |
| A＋QM9推定特徴 | 1.609 / 2.035 / -0.374 | 3.896 / 5.166 / -0.477 | 2.737 / 4.093 / 0.303 |
| 保存済みHSPiT比較値 | 0.979 / 1.336 / 0.408 | 2.818 / 4.103 / 0.068 | 2.411 / 3.704 / 0.429 |

[18件の学習内選択](expanded-reference-head.md)に対して、AのδH MAEは3.275→2.774、
A＋QM9は3.237→2.737へ下がりました。一方、両者のδD・δPは悪化しました。
固定したMAE比1.10以下・系列ブートストラップのMAE差の片側95%上限0.30以下、
68系列・2,000反復・seed 20261010の条件を保持し、12判定すべてが未通過でした。
モデルや追加対象をこの結果に合わせて選び直していません。

学習特徴の範囲外は887件、範囲内は126件。範囲内だけへ目標を縮めません。
負のδP/δHはAが159/73件、Bが142/19件、Cが184/82件、A＋QM9が142/70件でした。
切り上げずに失敗を保持しています。独立校正群がなく、校正済み区間はありません。
同一構造に異なる参照値を持つ13件も従来の評価規約で保持しました。
データ量は増やせましたが、未確認な参照値の追加で広い集団の精度は揃って改善していません。
通常のHSP推算・高分子・イオン・混合物・長鎖界面活性剤への適用範囲は広げません。

## 検証と保存記録

追加した配列用ハイブリッド選択には、外側の検証ラベルを大きく変更しても
学習側の基礎予測・残差候補が変わらないテスト、系列分割、JSON状態の復元テストがあります。
独立したスクリプトでプロジェクトの学習・選択関数を使わず、sklearnのRidgeとScalerから
全候補、5外側・20内側分割、予測、NumPyの評価指標とブートストラップを再計算しました。
予測の最大差は1.43e−14、設定選択のスコア差は0、すべての比較判定が一致しました。
元の教師値の列順・構造順と、再読込み後の出典・未知条件・利用範囲も確認しました。

学習前の静的確認で表示用の指標キーの誤りを修正し、未実行の最初の準備計画を
失効記録付きで保持しました。修正前に特徴抽出・学習・評価ラベルの読込みはしていません。
計画SHA-256は`b2662e02ae39442ee68432fd4860e1f4a67a996ea8b3ec169a31c054660033ee`、
予測レシートは`7340c349659c3d59fe8902b945f1b8d0b57c8940b52e1df595882beeb016c1ca`です。
これらはローカル保存物の照合用で、許諾や物理精度の証明ではありません。

次は未照合の候補の識別子確認を、提供元の混雑が解消した後に再開します。
実用精度に向けた実測の拡張は別課題として、測定法・試料条件・独立評価集団を揃えます。
