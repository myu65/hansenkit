# ALPB溶媒応答の特徴量を追加した比較

2026-10-12、固定構造で計算した水・ヘキサンの溶媒応答8特徴を追加しました。
学習系列だけで判定する「δD・δP・δHすべてのMSEを1%以上改善」という条件を
満たさなかったため、[既存のsoftplus v2](learned-nonnegative-response.md)を維持しました。
保存モデルの選択は[12, 6, 12]で、`ALPB_features_used_by_adopted_head=False`です。
計算した特徴を保存したことと、最終モデルがその特徴を使ったことを区別します。

## 計算した範囲

元の1,770行には1,759構造があり、重複行の差は11行です。元から構造計算が欠けた
8構造を除く1,751構造について、既存の3配座それぞれで2溶媒の単点計算を実施しました。
合計は`1,751 × 3 × 2 = 10,506`回で、実行失敗0件です。全1,770行と欠損理由を保持し、
欠損構造を学習・評価の集団から除外していません。新しい配座生成、構造最適化、
気相の再計算、失敗後の再試行は行っていません。

GFN2-xTBの固定構造にALPBを用い、熱力学温度298.15 K、電子温度300 K、
`bar1M`の標準状態（1 barの理想気体から1 mol/L溶液）を固定しました。
水の`Gsolv`、ヘキサンの`Gsolv`、水の`Gelec`、水の`Ghb`について、3配座の
等重み平均と母標準偏差を取り、単位Ehの8列としました。Boltzmann平均や
物理的な不確実性ではありません。ALPBの方法は[原論文](https://doi.org/10.1021/acs.jctc.1c00471)、
用語と標準状態は[xTB公式文書](https://xtb-docs.readthedocs.io/en/latest/gbsa.html)を参照してください。

実行したWindows版xTBは6.7.1pre、ソースrevision `5071a8869720fb0ecd788af977159869b64a277c`です。
[公式release](https://github.com/grimme-lab/xtb/releases/tag/v6.7.1)のタグrevisionと
Windowsビルドのrevisionを混同せず、実行バイナリと水・ヘキサンのパラメータを
個別のハッシュで固定しました。`Ghb`は電荷・表面に依存する経験的な溶媒補正項です。
実測した水素結合強度やHansenのδHではなく、`Gelec`もδPへ置き換えていません。

## 学習側だけで決めた採用判定

HSP教師は従来と同じ757行・402系列の`published_reference`です。
実測／推定の系譜や測定条件が不明な公開参照値を、新しい独立実測として数えません。
化学105特徴、固定MoLFormer全768次元、既存物理特徴とQM9推定特徴を保持しました。
今回の方式では8列を既存物理ブロックへ追加し、24→32列、QM9付きでは30→38列にしました。
損失・数値拒否条件・13候補は既存方式と同じです。

元の外側5分割・内側5分割の系列を保持し、前処理と候補選択は各学習分割内だけで行いました。
中央値と欠損マスクも学習側だけから作り、その分割で全欠損の列は使用しません。
検証側の値で列を有効化したり、欠損値を補う設定を選んだりしていません。
元の重複・骨格・互変異性体・系列の予約を保ち、Excelは評価専用です。

以下は外側の学習内検証予測から求めた、系列を等重みとする元のδのMSEです。
単位はMPaです。固定した採用条件は各成分で`追加方式 ≤ 0.99 × 基準方式`でした。

| 成分 | 基準方式 | ALPB追加方式 | 1%以上の改善 |
| --- | ---: | ---: | --- |
| δD | 0.317243 | 0.313401 | 通過 |
| δP | 2.600983 | 2.637616 | 未通過 |
| δH | 1.281181 | 1.277337 | 未通過 |

δPは悪化し、δHの改善は1%未満でした。3成分の採用条件を満たさないため、
外部評価を読む前に基準方式のモデルと全1,770行の予測を固定しました。
評価結果によってこの判定や特徴量・設定を変更していません。
