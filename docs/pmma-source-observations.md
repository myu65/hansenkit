# PMMAの原観測と、単位が不明な分子量を保存する

2026-10-13、[密度特徴の比較](polymer-density-transfer.md)が保留系列で改善しなかった後、
原試料と測定条件を区別できる実験資料を確認しました。
[PMMAのIGC研究の公式SI](https://acs.figshare.com/articles/journal_contribution/28068124)の
Table S1にある28溶媒の目視観察を、既存の`material-lookup`で参照できる
ローカルの評価候補台帳へ準備しました。追跡は[#106](https://github.com/myu65/hansenkit/issues/106)です。

28行は1試料の溶解観察です。28種類の高分子や、28組のHSP正解ではありません。
独立実測HSP3成分として新たに採用した行は0件、モデル学習も0件です。

## 単位を仮定しない小さいスキーマ拡張

元の`ReportedWeight`は正の`value_g_mol`を必須にしていました。
今回のSIはMwを報告していますが、閲覧できた一次資料ではその単位を明示確認できませんでした。
数値の大きさや通常の慣習を根拠にg/molへ対応させません。

`value_as_reported`と`unit_as_reported`で、元の文字列と、報告されている場合だけその単位を保持します。
資格を確認したg/mol値がなければ`value_g_mol`は`null`です。
原文もg/mol値もない報告、空白の原文・単位、非正・非有限のg/mol値は拒否します。
従来の正のg/mol値を持つ台帳はそのまま読めます。原文字列からの数値解釈・換算は行いません。

```python
from hansenkit.material_observations import ReportedWeight

reported = ReportedWeight(
    kind="Mw",
    value_as_reported="authored nominal 12,345",
    unit_as_reported=None,
    method=None,
)
assert reported.value_g_mol is None
```

この例は自作の文字列です。MwをMnへ読み替えたり、DPや代表鎖構造を計算したりしません。
正規化済みの数値を呼出側が宣言しただけでは、単位や試料の証明にはなりません。

## 全28行のローカル読込み

原SIはACS Figshare article28068124/file51316672、CC BY-NC 4.0です。
39,574 bytesと発行元MD5を照合し、PDFのSHA-256は
`079f365d3c27661c8a9c69f26549a8e85d7271d14d335565f1090df3a4c8afe3`です。
別の担当も3ページの全行を目視し、溶解10・不溶18、欠損・部分溶解カテゴリなしで一致しました。

原文の溶媒名・結果・試料Mwの文字列を保持しました。方法は試料50 mgに溶媒0.5 mLを加え、
振とうして24時間後に目視するものです。最終液量を測ったものではないため、w/v%を計算しません。
単位を未確認のMw、Mn、分散度、末端、立体規則、数値温度、相、溶媒の構造は補いません。
名前を推測したSMILESや、完全な材料系列の分離証明も作っていません。

新しい出典別の準備・参照許可は`operator_assumption`、科学研究・私用・非商用のローカル限定です。
先の分類専用レビューを学習許可へ変更していません。
原PDF、台帳、レビューとCLIの出力は無視対象に保存し、Gitや配布物へ含めません。
準備と参照では元PDF・準備許可・台帳のハッシュと、全28行の出典・試料対応を検査します。

全行読込みと28件の個別照会・保存復元が一致しました。未報告の試料・溶媒の照会は0行です。
CLIでも対象試料の28行を読め、別のPMMA gradeは`no_reported_observation`になりました。
出力は出典の観察で、数値のHSP推算や条件をまたぐ適用判定ではありません。
単位不明の原報告と既存の正規化値について、11件の新しい自作テストを含む全754テストが通過しました。

SIの溶媒HSP列、Table S2のχ、球のフィッティングは採用していません。
[原著の公開要旨](https://pubs.acs.org/iecred/article/64/1/81/3706098)は5分子量のIGC由来HSPを報告しますが、
IGC温度、プローブ座標の出典、条件と材料の対応を確認する本文が必要です。
現在の目視観察を平衡溶解度やHSP3成分へ置き換えません。

次の情報が得られる検証は、試料と数値温度を明示した新しい溶媒適合性観測です。

既に見た保留結果を使う追加調整や、通常の高分子・EO/PO・混合物HSPの適用範囲変更は行いません。
