# 小さな回帰ヘッドのアーキテクチャ比較

2026-10-11、同じ50構造・51参照行・40系列で4方式を追加比較しました。
RBF回帰ではδP MAEが化学Ridgeの4.013から2.448、δHが2.774から2.458へ下がりました。
ただしδDは改善せず、全3成分の非劣性は未達です。
評価は以前から探索した1,013構造・68系列の公開参照値です。
新しい盲検や独立実測の精度証明として扱いません。

## データと固定した方式

[前回の50構造の学習](reference-data-expansion.md)と同じ教師値・構造・分割予約を使いました。
測定系譜、試料状態、温度は未確認のまま、ラベルは`published_reference`です。
別の正確な計画とローカル利用レビューで`audit_basis="operator_assumption"`を記録しました。
科学研究・私用・非商用に限定し、原表・特徴・予測配列・学習済み重みは公開しません。
Excelの値・係数、参照GCの出力、既存モデルの予測値は学習・調整・校正に使っていません。

MoLFormerは固定した確認済みCPU表現をハッシュで照合して再利用しました。
エンコーダの再実行、重みの更新、新しい外部重みや依存の取得はしていません。
新しいヘッドでは105化学特徴と、学習群だけから求める8つのEmbedding主成分を結合します。
化学特徴、Embedding、主成分スコア、教師値の正規化も、その学習群だけで求めます。

| 方式 | 固定した候補 |
| --- | --- |
| A 化学Ridgeの対照 | 従来の成分別Ridge選択。同じ51行で以前と完全に同じヘッド |
| 結合Ridge | 113特徴。alpha 0.01～10,000の7候補 |
| RBFカーネル回帰 | 教師値を学習平均で中心化。alpha 0.1/1/10、gamma 0.1/1/10を特徴数で割った9候補 |
| ExtraTrees | 128本、最大深さ2/4、葉の最小件数4/8の4候補 |
| MLP | tanh隠れ層8/16ユニット、L2 alpha 10/100の4候補。LBFGS、最大600反復 |

各方式に明示した学習平均の候補を加え、成分ごとの系列MAEで設定を選びます。
1e−12以内の同点は平均値、その後に固定した候補順を優先します。
各ヘッドはJSONの数値状態で保存でき、pickleや外部コードの取得は不要です。
配列用の`ResearchHead`は資格確認済みのHSPModelではありません。
入力の使用許可、化学範囲、完全な系列予約の確認は呼出し側の責任です。
通常のCLIへ自動で有効化せず、高分子・イオン・混合物・長鎖の拒否は維持します。

## 学習群内での方式選択

5つの外側系列分割の学習群内で、さらに5分割して候補設定を選びました。
正規化・PCA・回帰は内側の学習行から求め、外側の検証ラベルや特徴で設定しません。
外側で得た系列ごとのMAEを等しく平均し、3成分の平均で方式を選びます。
全51行での最終設定選択も、学習群内の5系列分割だけで行いました。

| 方式 | 入れ子検証の系列MAE δD / δP / δH |
| --- | --- |
| A 化学Ridge | 1.144 / 2.074 / 1.280 |
| 結合Ridge | 1.145 / 1.863 / 1.253 |
| RBF | 0.976 / 1.691 / 1.226 |
| ExtraTrees | 1.074 / 2.178 / 1.907 |
| MLP | 1.168 / 1.513 / 1.188 |

学習側で選ばれた方式はMLPで、最終設定は16ユニット・alpha 10でした。
RBFの最終設定はδDがalpha 0.1/gamma 1、δP・δHがalpha 0.1/gamma 0.1です。
全1,064行の予測と方式選択を保存・固定してから、1,013行の外部参照値を読みました。
外部評価でRBFの成績がよくても、学習側の選択をRBFへ置き換えていません。
方式・主成分数・候補・反復予算・評価対象も、この結果に合わせて変更していません。

以前と同じMAE比1.10以下、68系列・2,000回のブートストラップによる差の片側95%上限
0.30以下を維持しました。RBFのδPだけが通過し、全3成分を満たす方式はありません。
RBFのδPのMAE比は0.869、差の95%上限は−0.116でした。
δHのMAE比は1.020でも、差の上限0.749で未通過です。
ExtraTreesはδDのMAEを下げましたが、δHは化学Ridgeより悪化しました。
成分ごとに外部評価の最良方式を組み合わせる学習はしていません。

特徴範囲のOODは以前と同じ887件、範囲内は126件です。
13構造の異なる参照値も元の評価規約で保持し、良好な対象だけへ評価を縮めません。
負のδP/δHは化学Ridgeが159/73件、結合Ridgeが137/75件、RBFが29/0件、
ExtraTreesが0/0件、MLPが51/10件でした。予測値の切り上げはしていません。
比較のブートストラップは予測区間の校正ではなく、独立校正群もありません。

## 最適化の失敗と検証

4新方式の候補検証は計720 fitでした。そのうちMLPの105 fitに収束警告があります。
最終MLPも600反復まで進まず、27反復でLBFGSの異常終了による未収束を記録しました。
有限の予測が得られたことを最適化成功と扱わず、予算変更や黙った再試行はしていません。
この選択結果を、安定した実用モデルとして採用していません。

プロジェクトの学習・融合・予測関数を使わない独立sklearn実装で、全候補、
5外側分割、最終設定と方式選択、保存JSONの予測、評価指標、ブートストラップを再計算しました。
全予測の最大差は3.02e−14、候補スコア差は2.67e−15で、方式選択と全判定が一致しました。
正規化の学習行限定、JSON復元、破損した木の循環拒否、物理資格を名乗る状態の拒否もテストしました。
数値の一致は、ラベルの測定系譜や物理適用範囲を確定するものではありません。
