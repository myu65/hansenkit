# 計算された電子物性を学習してHSPへ転用する比較

2026-10-12のローカル研究では、655,713構造でHOMO–LUMOギャップを学習し、
その予測をHSPの特徴量へ加える比較を完了した。HSPの学習系列では全成分の誤差が
小さくなったが、実行前に固定した「各成分で1%以上改善」の採用条件に届かなかった。
追加特徴量は採用せず、従来の非負応答モデルを保持した。実用精度の資格は未達である。

[PCQM4Mv2の公式説明](https://ogb.stanford.edu/docs/lsc/pcqm4mv2/)によれば、
教師はPubChemQC由来のDFTで計算された電子ギャップで、単位はeVである。
HSP、実測の水素結合強度、液体の凝集エネルギーの教師ではない。
公式CID分割の成績と、今回の保守的な系列分割の成績は直接比較できない。

全HSP構造について、既存の骨格・トポロジー・互変異性体の予約5,176件を保持した。
元の全資料監査には未知の結び付け39件があり、その記録を残したうえで、
補足的な構造監査によって既知の結び付けと隔離対象を確認した。
不完全な構造を含む連結系列を全資料で隔離し、元の化学構造を特徴量入力に保持した。
これは構造分割の証明であり、物理精度や資料の公開許諾の証明ではない。

| 補助学習の区分 | 構造数 | 系列数 |
| --- | ---: | ---: |
| 学習 | 655,713 | 63,210 |
| calibrationとして隔離した部分 | 178,994 | 13,576 |
| testとして隔離した部分 | 147,470 | 13,445 |

74個の化学特徴による固定RidgeをA、固定Morgan256によるRidgeをBとした。
CはAと、4つの学習系列分割で作るOOF残差をBで学習した補正の和である。
正規化と残差作成には学習部分だけを使い、alpha=100を固定した。
モデルを固定した後に隔離部分の数値を読み、全件を評価した。
calibration部分を不確実性の校正に使ったわけではない。

| ギャップ予測方式 | test MAE / eV | test RMSE / eV | 全行R² |
| --- | ---: | ---: | ---: |
| A | 0.426320 | 0.547227 | 0.740986 |
| B | 0.495419 | 0.639045 | 0.646775 |
| C | 0.394331 | 0.508253 | 0.776566 |
| 学習部分の平均 | 0.838689 | 1.075543 | -0.000565 |

独立したNumPy実装で学習重みを再構成し、全行・全系列のMAE/MSEを照合した。
重みの最大差は8.54e-12未満だった。一方、ほぼ一定の教師値を持つ系列のR²は
浮動小数点の分散計算に敏感で、8つの系列平均R²に不一致が残った。
元の値と独立計算の値を保存し、系列の除外・数値の切詰め・許容誤差の変更はしていない。
その系列平均R²をモデル選択や精度の優越主張に使わない。

HSP転用では、A/B/Cのギャップ予測をすべて固定順で追加し、ギャップのtest成績で
採用する列を選ばなかった。757行のHSP公開参照値、元の外側5系列分割、
内側5系列分割、13候補、損失、solverの拒否条件を保持した。
各外側学習部分の中で前処理と候補選択を作り直した。

| HSP成分 | 従来方式の外側系列平均MSE | 追加方式 | 改善率 |
| --- | ---: | ---: | ---: |
| δD | 0.317243 | 0.315542 | 約0.54% |
| δP | 2.600983 | 2.597643 | 約0.13% |
| δH | 1.281181 | 1.269238 | 約0.93% |

全成分の改善が固定した1%基準に届かず、最終モデルに新しいPCQM特徴量は入っていない。
最終モデルの数値状態は従来方式と完全一致した。全1,770行の出力の最大差は
8.89e-15未満で、異なる実行間のビット単位一致は主張しない。
適用判定・拒否・構造順序・系列・OOD判定は一致した。

最終モデルと全予測を固定してから、評価専用1,013構造を照合した。
δD/δP/δHのMSEは1.483965/11.183347/7.157551、
変更しないHSPiT比較値は1.785945/16.837093/13.721079だった。
この既に参照した評価は記述的比較であり、新しい独立実測テストではない。
HSP教師は系譜不明の`published_reference`757行のままで、独立実測の追加は0行である。
OODのδD、校正した不確実性、高分子・界面活性剤・混合物・イオン性物質のHSP資格は未達で、
既定の推算拒否を維持している。
