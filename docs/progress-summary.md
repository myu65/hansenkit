# 開発と検証で、どこまでできたか

2026-10-14時点では、構造の読込み、学習、予測、モデルの保存と読込み、CSV入出力が動いています。
材料や配合条件を指定して、原資料の観測を検索する機能も使えます。
未知の高分子・界面活性剤のHSP3成分を実用精度で推算する目標は、まだ達成していません。

小分子は、1,013化合物の同じ参照データで3成分とも平均二乗誤差がHSPiTの比較値を下回りました。
化学特徴、固定したMoLFormer、計算化学の補助特徴を組み合わせた研究モデルで比較しています。
負値を出さない方式も学習し、この1,013行すべてで非負の数値を返しました。
これは公開参照値との比較です。独立した実測の精度や、学習範囲から外れる分子のδD精度は未確認です。
通常CLIの合成データデモと、このローカル研究モデルは別に扱います。
方式と数値は[小分子の比較記録](learned-nonnegative-response.md)に残しています。

高分子では、密度の参照値を予測する課題で改善を確認しました。
学習に使わない74系列104行を系列ごとに同じ重みで評価すると、誤差指標RMSEは0.0842g/cm³でした。
訓練平均を返す対照の0.1224g/cm³より小さい値です。
元資料では末端や温度などが不明で、市販試料の密度を保証する段階ではありません。
追加資料の照合で見つかった未適用構造のつながりは、その系列全体を隔離して再学習しました。
[密度の学習と再監査](polymer-density-isolation.md)に条件を記録しています。

予測密度を特徴に加えた比較では、単一の溶解度指標の訓練内の平均二乗誤差は1.49%改善しました。
一方、学習に使わない別10系列のRMSEは4.875から4.917へ増えました。
ここでいう「悪化」は、参照値からのずれが大きくなったという意味です。
凝集エネルギー密度の比較は訓練時の採用条件に届かず、保留値を評価せずに停止しました。
この結果を使って追加調整はしていません。条件は[密度特徴の比較](polymer-density-transfer.md)に残しています。

分子シミュレーションは、エタノール・PEG8・指定したEO/PO鎖を各3回、8,192点ずつまで実行しました。
エタノールだけが統計基準を通過し、PEG8とEO/PO鎖では時間変化や反復間の差が残っています。
統計基準の通過だけでは、平衡状態や力場の精度を確かめたことにはなりません。
HSPの3成分への分解も未確認です。[全反復の診断記録](polymer-research-followup.md)に残しています。

PMMAは、同じ1試料について28溶媒の観測を検索できます。
報告された分子量Mwの単位や試験温度は、分からないまま保存しています。
MwからMnや代表鎖を計算せず、別のPMMA試料へも一般化していません。
[原観測の読込み](pmma-source-observations.md)では、全754テスト、合成CLI、配布物検査と6つのCIが通過しました。

今回は、活性剤の可溶化を測った原表から、水の3点と6種類の活性剤の72点をローカルに整理しました。
75点すべてで別担当の転記と一致し、元の条件で検索できました。
計算による理想溶解度とHSPiPのHSP値を混ぜず、相対不確かさも原表の表記のまま保持しています。
この75点は同じ薬物の可溶化観測で、75化合物のHSP正解ではありません。
今回はモデルの追加学習を行っていません。条件と不明点は[原表の確認結果](surfactant-solubilization-intake.md)に残しています。

[出典の追加確認](solubilization-source-qualification.md)では、原報6gradeの公称組成とEO数をメーカーの説明と照合しました。
現在の製品情報だけでは、2021年の試料の分子量や分布は確定しません。
薬物の公称構造は既存HSP予約系列に一致し、75点は候補・評価専用のままです。
混合媒体のモル分率の定義と材料の対応にも不明点が残り、換算や追加学習は行っていません。
別資料で学習を始める際は、材料と薬物の系列を先に照合し、学習・評価の分け方と仮説を固定します。
未知の材料で精度を検証するには、試料と条件を明示した別の観測が必要です。
既に見た評価値に合わせて設定を変えたり、現在の結果を実用精度の証明にしたりはしません。
