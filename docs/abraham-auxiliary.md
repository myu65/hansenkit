# Abraham参照記述子の補助学習とHSPへの転移

新しい公開資料からHSP予約を除いた783構造・442系列を準備し、435構造で
E/S/A/B/Lの参照記述子を学習しました。別の186構造で補助物性を評価し、
固定した推定特徴を11件のHSP参照学習へ渡して1,013構造を比較しました。
化学特徴の固定回帰よりδDなどのMAEは小さくなりましたが、全3成分の非劣性は未達です。
参照記述子はHSPの正解や量子物性と別に数え、通常の推算範囲を変更しません。

## 出典と利用範囲

[Brown, 2022](https://doi.org/10.1007/s10953-022-01162-2)の方法と、
[作者のIFSQSARリポジトリ](https://github.com/tnbrowncontam/ifsqsar)を照合しました。
版 `39d09a775ba797a2d7c86ae18c3168625f876915`のExcelは1,312,285 bytes、SHA-256は
`6965b00e40070d0da637fc20eace986f94505b750d9638d636d2e19f1bc9a250`です。
Git blob SHA-1もAPIツリーの値と一致しました。作者のコード・係数・重みは取得・実行していません。

元Excelを編集せず、Bundled Python/openpyxlで読込み、別のOpenXML読みで再照合しました。
溶質表4,990行のうち、作者のtrain/validate区分は4,910行です。
出版時の4,974件を現在のファイル件数と同一視しません。旧研究のみの33行と
追加PFAS47行は、今回の学習候補へ入れていません。
系パラメータ表の91実験校正行・970経験予測行、15,770分配比行も今回の教師・特徴に使いません。
計算で求めるV/Vfも教師から除き、E/S/A/B/Lの元の記述子尺度を保持しています。
係数表、予測値、分配比の観測行をHSP化合物の件数に足しません。

この表の基盤にはUFZとAbrahamの資料が含まれます。

帰属付きの研究・私用を認め、商用利用を認めません。原論文のCC BY 4.0だけで
元のデータ全体をMIT・商用可として扱いません。コードのライセンスファイルも検出されず、
READMEのGPL依存への言及を、数表の許諾とは扱っていません。
正確なローカル実験をユーザーの監査通過仮定に記録し、用途は`scientific_private_noncommercial`です。
原数表、材料・構造一覧、特徴/予測配列、学習済み状態、外部実装はGitへ含めません。

作者は予測された記述子を除いたキュレーションを説明していますが、現行表の

個別の化学名・CAS・立体・温度・測定系譜は独立に確定していません。
ラベルは`published_reference_auxiliary`で、実測HSPや認証済み実験値には格上げしません。

## 予約、特徴と固定計画

全HSP予約1,266構造・132骨格・2,798別名を維持しました。
元表の4,066行はこの予約に重なり、27行の未確認電荷、8行の不完全な互変異性体探索、
11行の未対応元素、3行のラジカル等も除外しました。残る候補795行のうち、
同じ正規化構造で5記述子の組が違う6構造をまとめて除き、783構造になりました。
この除外は学習前の一貫した品質規則で、HSPやテスト誤差を見た除外ではありません。
数値、構造、立体を修正・平均化・中和せず、未確定の名前からSMILESを推測していません。
互変異性体と骨格の旧リンクを残し、全採用群のHSP予約重複と分割間別名重複は0です。

783構造すべてに105化学特徴と確認済み固定MoLFormerの768次元を作りました。
CPUのみを使用し、最大126 tokens、上限202以内で切詰めは0です。
データ行・同系列・計算記述子・事前学習構造の件数は別に記録しています。
MoLFormerの重みは更新せず、事前学習集団との構造重複は未知のままです。

計画SHA-256: `8eb12f4f09a3396be9bc4a1c1f158857328d4d273d6e27aa93945f0f3bf98121`。
系列を先に分け、学習435構造/264系列、校正162/89、評価186/89としました。
作者の元のtrain/validate割当を、この実験の分割に流用していません。
Aは化学特徴、Bは固定Embedding、Cは4分割で系列を外して作ったA残差のEmbedding補正です。
全回帰をalpha 100で固定し、標準化は各学習分割だけで行います。
HSPへの転移3方式も事前に固定し、補助テストで勝った方式を選んでいません。

## 補助記述子の結果

各記述子の元の尺度でのMAE / RMSE / R²です。MPa^0.5へは変換しません。

| 方式 | E | S | A（HB酸性） | B（HB塩基性） | L |
| --- | --- | --- | --- | --- | --- |
| A 化学特徴 | 0.215 / 0.281 / 0.879 | 0.443 / 0.610 / 0.545 | 0.166 / 0.232 / 0.691 | 0.198 / 0.295 / 0.834 | 0.566 / 0.794 / 0.958 |
| B 固定MoLFormer | 0.268 / 0.340 / 0.822 | 0.462 / 0.595 / 0.567 | 0.268 / 0.368 / 0.223 | 0.248 / 0.327 / 0.795 | 1.015 / 1.372 / 0.874 |
| C 残差補正 | 0.225 / 0.289 / 0.871 | 0.474 / 0.620 / 0.531 | 0.336 / 0.432 / -0.074 | 0.209 / 0.301 / 0.827 | 0.536 / 0.713 / 0.966 |

CはLのMAEがAより5.2%小さくなりましたが、他の4記述子では悪化しました。
特にHB酸性のR²は負です。原子数やEmbeddingだけで相互作用の尺度を一様に改善したとは言えません。
負のA/B予測はAが19/1件、Bが25/2件、Cが35/3件で、切り上げていません。
学習特徴の範囲外は23件です。これらの値を物理推算として採用しません。

校正89系列の最大絶対残差から、各記述子について90%区間を計算しました。
評価側の系列全体の被覆率はAで0.843–0.944、Bで0.899–0.978、Cで0.876–0.955です。
5記述子を同時に全行で覆う系列は0.652/0.775/0.753で、5成分同時の90%保証ではありません。
この参照尺度の校正をHSPや実測材料へ移していません。

## 1,013構造のHSPへの転移

固定した補助ヘッドから5つの推定特徴を作り、105化学特徴へ加えました。
HSPの11参照構造だけでRidge alpha 100を学習し、予測をハッシュで固定してから
以前と同じ1,013構造・68系列の参照評価値を読みました。HSPiT/MathieuのHSP Excelの値・係数・比較値、
HSP教師の疑似ラベルは学習・特徴・校正へ使いません。
新しいAbraham Excelの5記述子は、別の補助タスクの教師として使用したものです。
補助の435学習構造を、HSPの11正解へ加えて数えません。

単位はMPa^0.5。このHSP参照集団は以前から探索済みで、盲検・独立実測の精度証明ではありません。

| 追加する補助ヘッド | δD MAE / RMSE / R² | δP MAE / RMSE / R² | δH MAE / RMSE / R² |
| --- | --- | --- | --- |
| A 化学特徴ヘッド | 1.317 / 1.645 / 0.103 | 2.798 / 3.676 / 0.252 | 3.212 / 4.532 / 0.145 |
| B 固定MoLFormerヘッド | 1.467 / 1.808 / -0.084 | 2.694 / 3.528 / 0.311 | 3.183 / 4.488 / 0.162 |
| C 残差補正ヘッド | 1.300 / 1.625 / 0.124 | 2.761 / 3.661 / 0.258 | 3.228 / 4.585 / 0.125 |

以前の固定AのδD MAE 1.435に対し、C特徴付きは9.4%小さくなりました。
しかし保存済みHSPiTの0.979には届きません。δHも既存比較法の2.411より大きいままです。
以前と同じMAE比1.10以下・系列ブートストラップの差の片側95%上限0.30以下では、
B/C特徴付きのδPだけが通過し、全方式の全3成分非劣性は未達です。
13構造の参照値不一致も保持し、学習範囲内44件へ目標を縮めません。
HSPの範囲外は969件、各方式の負のδP/δHは2/2件です。物理HSPや校正済み区間に採用しません。

## コードと検証

`AuxiliaryManifest`は量子物性と公開参照補助値を別のラベル種・タスク・行数として保存します。
`use_scope="scientific_private_noncommercial"`では、監査方法に関係なく再配布許可を拒否します。
参照補助モデルを量子・HSPの件数として出力せず、用途を再読込み後も保持します。
追加3テストでこの保存と制約を検証しました。通常のHSP推算の適用範囲は広げません。

独立したOpenXML読みで元の4,990溶質行を照合し、採用783行の元ターゲット、化学特徴、
全HSP予約・系列別名、4残差分割を確認しました。NumPyの正規方程式で保存ヘッドを再計算し、
補助指標・校正・全1,013予測・3成分指標・2,000回の系列ブートストラップを照合しました。
最大HSP予測差は8.88×10⁻¹⁵です。783構造のCPU Embeddingを再計算し、最大差は0でした。
保存後の設定選択・教師の入替え・テスト行の削除はしていません。

新しい独立実測HSPラベルは0です。今回の参照特徴の改善だけで、1,000化合物の実測非劣性、
高分子・長鎖界面活性剤の検証済み推算、商用可の公開モデルを達成したとは扱いません。
