# 許可済み係数による参照計算

`reference-gc` は、ローカルで使用を確認した係数と完全な原子所属を使う、
基団法の計算再現用コマンドです。数値の種類は `coefficient_reference_hsp`。
通常の `predict` の適用範囲を広げず、学習・擬似ラベル生成にも接続しません。
物理精度は未検証で、校正された不確実性を出しません。

独自の6種類の基団は methyl、methylene、methine、vinyl_methine、ester、alcohol。
エステルの炭素・酸素2原子、アルコールの酸素、残りの炭素を重複なく割り当てます。
単一の中性・非環式構造を対象とし、全重原子に所属が必要です。
酸、ケトン、エーテル、芳香族・環状構造、四級炭素、イオン、同位体、混合物などは拒否します。
EO/POのエーテルにも未対応で、未知の末端や組成を推測して埋めません。

参照した一次資料は
[2025年の脂質ナノキャリア論文](https://doi.org/10.5530/ijper.20254852)の
Table 2、印刷ページS74（[PDF](https://www.ijper.org/article/59/1s/s71.pdf)の4ページ目）です。
Table 1/2/4のHSPは理論計算値であり、脂質の溶解観察を測定しただけでHSPの独立実測値にはなりません。
QikPropの記述子や商用混合脂質の仮の構造は取り込みません。
記事のCC BY 4.0表記と、元の書籍等から来た基団定数の再利用許諾は別に確認します。
この実験ではユーザーの監査通過の仮定に基づくローカル参照計算だけを認め、係数表はGitに含めません。

この資料の表に合わせ、極性項は**基団種類ごとの合計力を二乗してから平方和平方根**を取ります。
同じ基団の個数を平方根の中で線形加算する別の約束には切り替えません。
一般的な基団法全体を実装したという主張もしていません。
表の極性力二乗列の単位見出しには次元の不整合があり、記録して保持しました。
ジリノレートのδHは表によって小数点以下の扱いが異なります。
係数の基準温度は資料から確定できず、`null` としています。

計算は、基団数を n、部分モル体積を V、分散力を FD、極性力を FP、
水素結合エネルギーを EH として、以下の約束に固定します。

- 全体積 = Σ nᵢVᵢ。負の部分体積は許し、全体積が正で有限であることを確認。
- δD = Σ nᵢFDᵢ / 全体積。
- δP = √Σ(nᵢFPᵢ)² / 全体積。
- δH = √(Σ nᵢEHᵢ / 全体積)。

FD/FPは `sqrt(J)*cm^(3/2)/mol`、EHは `J/mol`、Vは `cm^3/mol`。
出力は `MPa^0.5` で、余計な1000倍の換算は行いません。

## ローカルファイルと実行

係数JSONには `units`、`polar_convention="rss_of_group_type_force_sums"`、
`reference_temperature_k`（未知なら必ず `null`）、`groups` が必要です。
`groups` の各基団には `fd, fp, eh, volume` を指定します。必要な係数の欠落は拒否します。
完全なスキーマは `hansenkit.reference_gc.CoefficientDataset.model_json_schema()` で取得できます。
公開テストには自作の任意の算術定数だけを使っています。物理係数の雛形として扱わないでください。

別のレビューJSONには `sha256`、`source`、`declared_license`、`permission_evidence`、
`approved_by`、`audit_basis`（`documented_permission` または `operator_assumption`）、
`rights_status="approved"`、`local_reference_calculation_allowed=true` が必要です。
`training_or_pseudo_label_generation_allowed` と `public_redistribution` は `false` に限定します。
これは証拠を確認する人の宣言であり、自動的な権利審査ではありません。
ファイルは `local/` などGitが無視する場所へ置き、ハッシュの一致を確認して読み込みます。
外部ファイルや重みのダウンロードはありません。

```sh
uv run hansenkit reference-gc --parameters local/parameters.json --review local/coefficient-review.json --smiles "CCO"
uv run hansenkit reference-gc --parameters local/parameters.json --review local/coefficient-review.json --repeat-unit "[1*]CC(C)[2*]" --repeat-count 1000000000 --left-cap hydrogen --right-cap hydrogen
```

出力は標準出力のJSONです。両端は `hydrogen` またはポート付き末端SMILESで明示します。
分子モードへ鎖の引数を混ぜること、末端を省略することは拒否します。
明示構造は512重原子・8,192文字まで。Windows版RDKitが過大な構造の正規化で
スタックオーバーフローを起こしたため、正規化の前にサイズを検査します。
長鎖モードでは64単位を超えると4/16/64単位を組み立て、基団数の傾きの一致を確認します。
端の寄与を残した単位あたりの基団数で計算し、最大10¹²単位まで巨大な構造を確保しません。
代表鎖がサイズ上限を超える場合や加法性を確認できない場合も拒否します。
有限な計算値は材料のHSP精度・結晶性・温度依存性の検証を意味しません。

## 今回のローカル検証

係数・基団定義・除外条件を先に固定し、1,030件の構造から予測と拒否を保存して
ハッシュを確定した後、評価ラベルを読みました。学習、係数修正、テストに合わせた除外は行いません。
HSPiT Excelの係数・正解は学習にも特徴生成にも使っていません。
新しい一次論文の係数は、この独立した参照計算だけに使います。

- 論文の3つの計算例を再現。丸められた表との最大差は0.006675 MPa^0.5、事前許容差0.011。
- PE/PPは128単位、メチル末端のエステル鎖は100単位で直接計算と代表計算を比較。
  最大差は3.56×10⁻¹⁵ MPa^0.5。各10⁹単位でも有限値。
- 1,030件中112件（10.87%）だけが完全に対応し、918件は理由を記録して拒否。
  基団未割当493件、環式または非単一構造408件、その他の非対応17件。

同じ112件の参照値との比較です。単位はMPa^0.5。
測定系譜が確定していないため `published_reference` と扱い、独立実測テストと呼びません。
係数の基準温度も未確定で、温度を合わせた精度保証には使えません。

| 参照計算 | δD MAE / RMSE / R² | δP MAE / RMSE / R² | δH MAE / RMSE / R² |
| --- | --- | --- | --- |
| 新しい6基団係数参照 | 0.499 / 0.834 / -0.481 | 1.325 / 2.720 / 0.199 | 0.875 / 1.270 / 0.961 |
| HSPiT比較値 | 0.891 / 1.200 / -2.067 | 2.120 / 3.220 / -0.123 | 1.600 / 2.118 / 0.891 |

この小さい対応範囲での低いMAEは、1,000化合物の非劣性を証明しません。
δDはR²が負で、定数予測より良い説明力も示せていません。
別プロセスで全構造の適用判定、予測、拒否数、3成分指標を再計算して一致を確認しました。
学習済みモデル、原データ、係数表の配布はありません。

現在のExcel予約条件で、従来の1,030件からHSP校正に使える構造候補は11件・10系列だけです。
これは独立実測として確定した11件ではなく、HSP校正・本学習は実施していません。
2026年の医薬分子HSP論文（[DOI](https://doi.org/10.1016/j.molliq.2026.129267)）も調べましたが、
著者補足データを公開経路で取得できず、追加のHSP正解として採用していません。
次は独立した測定系譜・構造・条件を持つ校正資料と、エーテル等の欠けた基団の一次資料を確保します。
係数を追加する場合も別の版と実験計画を作り、このテストを未閲覧の検証と再利用しません。
