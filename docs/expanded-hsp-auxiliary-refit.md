# 拡張HSP予約での大規模補助再学習とHSP転移

2026-10-12。[構造再監査](expanded-hsp-auxiliary-audit.md)で衝突した旧モデル5資料を、
全5,176予約別名と新しい系列分割に従って実際に再学習しました。
さらに、53,670分子で学習した新しいQM9モデルを、757行のHSP学習へ転移しました。
現在の目的は1,013構造の参照MSE、高分子・長鎖の適用資格、1万件以上の学習を含みます。
今回の追加学習は前二者の検証に使う計算／参照補助物性であり、1万件のHSP実測正解ではありません。
高分子HSP3成分の資格を完成したとは扱いません。

## 学習方法と補助物性の結果

元の特徴・固定MoLFormer cache・元ターゲットと単位を保持しました。
QM9は768座標のRidge α=100。その他はA化学、B固定Embedding、C系列4分割で得たA残差を
Bで補正する方式です。α=100と分割種を事前固定し、テストで選び直しません。
SolQuestの残差分割は旧条件の4分割・shuffleなし、Abraham／MDはshuffleあり・seed42です。
各前処理と残差は、その分割の学習側だけから推定します。

## 53,670分子のQM9を757行HSPへ転移

新しい量子モデルは、全HSP学習／評価系列を予約してから学習しています。
HSP側の各外側分割で再学習するHSP教師モデルとは別の固定補助モデルです。
6個の生の推定量子座標を、既存24列のRDKit／3D proxyへ追加し、合計30列の物理特徴ブロックとしました。
液体の物理係数への変換、ターゲットの再命名、HSP擬似ラベルの生成はありません。
HSP学習・評価合わせた全1,770入力へのμ推定には負の値が74行あります。物理的な双極子ノルムではなく、
不正確さを含む回帰座標として保持し、切り詰めや行除外をしていません。
u0の1,770負値は元エネルギーの参照規約によるもので、μの負値と同じ不正性とは判定しません。

元の量子cacheのCUDA／torch metadataと、現在のCPU回帰runtime・HSP query cacheを別に記録します。
新しい重み取得、encoder更新、再Embeddingはありません。全68,057量子構造の元入力への対応と、
source cacheのhashを確認しました。異なるdeviceのquery cacheが量子cacheとbit同一だとは主張しません。

定数＋18個のbase kernel＋18個のQM9追加kernel、合計37候補です。
学習757行の外側5×内側5系列分割と最終の内側5分割で、成分別の系列平均MSEを使います。
補完・mask・標準化・PCA8・traceは学習内だけで推定し、候補順・同点許容差1e-12を固定しました。
全予測／選択／JSON復元を固定してから、変更していない評価1,013構造の数値を読みました。
