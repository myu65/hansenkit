# 水素結合・部分電荷・3D構造と二乗回帰の比較

同じ50構造・51参照行・40系列で、6条件を学習・比較しました。
水素結合サイト・電荷を加えたRBFはδH MAEを2.458から2.171へ下げました。
正の通常回帰はδDを1.680から1.097へ下げましたが、δPは悪化しました。
3D追加と二乗回帰による全成分の改善は確認できず、3成分すべての固定基準は未達です。
今回の構造計算や補助物性の推定は、液体の水素結合エネルギーを測るものではありません。
学習・評価ラベルは測定系譜、温度、試料状態が未確認の`published_reference`です。
独立実測のHSP精度や高分子への適用資格を、この比較から認定しません。

## 固定した6条件

| 条件 | 入力・方式 |
| --- | --- |
| RBF対照 | 前回と同じ105化学特徴＋学習群だけで求める8つの固定MoLFormer主成分 |
| サイト・電荷 | 対照＋ドナー／アクセプター密度・グラフ距離・厳密なGasteiger電荷の11特徴 |
| 補助物性 | サイト・電荷＋QM9由来の5特徴＋AbrahamのE/S/A/B/L推定値 |
| 3D追加 | 補助物性＋3コンフォマーの体積・MMFF電荷による双極子・形状など8特徴＋量子推定値／幾何体積の2比率 |
| 正の通常回帰 | 3D追加と同じ入力で、3成分を別々の128本のExtraTreesで学習 |
| 正の二乗回帰 | 通常回帰と同じ構造でδ²を学習し、予測値の平方根を取る |

RBFはalpha 0.1/1/10、gamma 0.1/1/10を融合特徴数で割る9候補です。
木の最大深さ2/4、葉の最小行数8/4の4候補を両方の木モデルで共通にしました。
二乗回帰は非負の葉平均を持ち、負の予測を後処理で切り上げません。
数学的な非負性と損失の仮説を試す方式で、凝集エネルギー密度を計算したという主張ではありません。
RBFの負の予測値もそのまま報告します。

すべての方式に学習平均だけの候補を加え、成分別の系列MAEで選びます。
5つの外側系列分割の学習群の中で、さらに5分割して設定を選択します。
正規化、EmbeddingのPCA、欠損補完、回帰は各分割の学習群だけで求めます。
方式全体の選択は外側系列MAEの3成分平均で行い、全1,064行の予測とともに固定します。
その後で従来の1,013構造・68系列の参照値とHSPiT比較値を開きます。
以前に結果を探索した評価集団なので、新しい盲検として扱いません。

## 特徴と計算の限界

Gasteigerは明示的水素を含む全原子で12反復し、`throwOnParamFailure=True`を指定します。
パラメータ不足、非有限値、電荷総和の不整合があれば電荷ブロック全体を欠損にします。
未知の原子を電荷0として計算から消す処理はありません。
詳細は[RDKitの固定版API定義](https://github.com/rdkit/rdkit/blob/fece8caa860bdf6c9c82bdb9253f22a0cf87150c/Code/GraphMol/PartialCharges/Wrap/rdPartialCharges.cpp)を参照してください。
ドナー／アクセプターはインストール済み`BaseFeatures.fdef`から取得します。
サイト数や候補対の近さは、結合の強さや形成確率ではありません。

3Dは明示したレビューで有効にするETKDGv3→MMFF94の固定3コンフォマー計算です。
最大60重原子・分子量500、Embedding上限1,000試行・タイムアウト10秒、
最適化上限600反復・1スレッド・プルーニングなしとしました。
分子ごとの乱数種は正規化構造のハッシュから固定します。
全原子のMMFFパラメータと3体すべての収束が必要です。
計算状態、各体の最適化結果、生成後の座標と部分電荷をローカルで保存し、
未収束分子の一部の体だけを採用したり、UFFへ置き換えたりしません。
[RDKitの一次API資料](https://rdkit.org/docs/source/rdkit.Chem.rdForceFieldHelpers.html)に従って判定しています。
MMFF電荷とGasteiger電荷は別モデルとして区別し、元の構造グラフを変更しません。
幾何体積は液体のモル体積ではなく、コンフォマー間の分子内エネルギー差は水素結合エネルギー・蒸発熱ではありません。
この計算で平衡状態、温度依存、誘起分極、液体中の相互作用を資格確認できません。

全1,064行でGasteiger電荷が揃いました。3Dの条件通過は1,057行で、
MMFF部分電荷の不整合2、Embedding不足2、最適化未収束1、
サイズ範囲外1、MMFFパラメータ不足1の計7行を3D欠損として保持しました。

QM9の固定推定値はμ・α・gapを残し、μ²／重原子数、α／重原子数を追加します。
μ・αが非負で、幾何体積が得られた場合にだけ体積による比率も作ります。
負の補助推定値を絶対値や0へ変換せず、条件を満たさない比率は欠損です。
単位はそれぞれDebye、a0³、Hartree、比率はDebye²/Å³とa0³/Å³です。
QM9の絶対内部エネルギーをHSP成分へ変換していません。

AbrahamのA/Bは水素結合酸性・塩基性の参照尺度の推定で、実測の結合エネルギーではありません。
既存の435行の補助学習には、今回のHSP学習群と同系列の13行がありました。
完全な元のHSP予約に今回の学習50構造の系列も加え、13行を学習側から除いて422行で再学習しました。
残る422行は257系列です。元の補助学習分割とalpha 100を使い、
校正・テストの補助ラベルを移していません。
再学習は固定MoLFormerの768特徴からE/S/A/B/Lを求めるRidgeです。
以前の435行の補助精度は、今回の422行モデルの精度とは呼びません。
QM9の61,622行の学習系列には今回の全HSP系列との重複がありません。
両補助モデルとも外部HSP評価系列との重複は0でした。
これらの件数をHSPの学習件数へ足しません。

1,064行中、QM9のμ推定38件、AbrahamのE/S/A/B/L推定は
それぞれ136/73/236/106/9件で負の値でした。
この出力を正しい物理量として保証せず、元の値と欠損理由をローカルに保持しました。
特にHSP評価領域へ移した補助モデルを、結合の強さの測定器として扱うことはできません。

欠損はNaNと理由を残し、補完にはその分割の学習中央値と欠損マスクを使います。
学習群に観測がない列は落とし、検証・評価群から中央値や利用可能性を学びません。
評価行を欠損や大きな誤差を理由に除外しません。

## 検証と次の実験

プロジェクトの学習・補完・融合・予測関数を使わない独立NumPy／scikit-learn実装で、
Abraham再学習、全候補の設定選択、5外側分割、最終予測、方式選択を再計算しました。
全予測の最大差は3.02e−14、候補スコア差は3.11e−15でした。
全体・OOD・範囲内のMAE/RMSE/R²、負の予測数、ブートストラップと全判定も一致しました。
保存・再読込み後もラベル種別、温度・状態の未知、私用・非商用、非再配布の来歴を保持しています。

327件のテスト、2件のローカル選択テスト、Ruff、合成データによるCLI／CSVを確認しました。
新しいテストは厳密な電荷失敗、全コンフォマー収束、再現性、レビューの資産ハッシュ、
双極子の並進・回転不変性、学習限定の欠損処理、正の木モデルのJSON復元などを確認します。
ソース配布・wheelを作成し、外部数表・重み・ローカル配列の混入がないことも検査しました。
通常のA/B/CとLightGBMの合成デモ、適用外入力の数値拒否を維持しています。

特徴数を増やすだけで3成分を一様に改善することは確認できませんでした。

密度・蒸発熱などからδDを検証する独立物性計画を分けて立てる候補があります。
いずれも条件・方式・計算予算を次の実験前に固定し、今回の評価値で係数・閾値を調整しません。
