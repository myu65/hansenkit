# HSP学習拡張後の補助モデル再監査

2026-10-12に、HSP参照学習を757行・746構造へ増やした後の補助モデルを再監査しました。
旧HSP予約では分離できていたモデルでも、追加したHSP学習系列に重なる場合があります。
QM9・SolQuest・Abraham・PolyOmicsの旧モデルすべてで、今回の予約に重なる学習行を確認しました。
これらの旧モデルを新しい757行のHSP学習へ転用する前に、集団を作り直して再学習する必要があります。
テスト行だけの削除や旧モデルの予測のフィルタでは修復できません。

[1,013構造の参照MSE実験](mse-reference-experiment.md)は、これらの旧補助ヘッドを使用していません。
今回の監査は、そのMSE結果に旧補助モデルの学習件数を足したり、実測の資格を付けたりするものではありません。

## 予約と検査

旧予約の1,266構造・132骨格・2,798別名をすべて保持し、現在のHSP学習757行について、
正規化された実際の構造から完全な互変異性体探索・旧Murcko・保守的位相の別名を追加しました。
合計は2,001構造・632厳密Murcko骨格・5,176別名です。
重複した11組のHSP参照値も構造予約へ反映し、数値の平均化・削除・教師の入替えはしていません。
学習・評価のHSP数値は、この構造監査では読んでいません。

最初に全構造から`HoldoutEmbargo`を構築した際、追加の裸Murckoグラフの自動探索が
`Incomplete bounded tautomer enumeration`で失敗しました。この実行は候補集団を生成せず終了しました。
失敗した元スクリプトと記録をローカルに保持しています。通常のコンストラクタや上限は変更していません。
今回のローカル予約は、旧別名の完全なスナップショットと、757行の実構造の完全な別名の和集合です。
人工的な裸骨格の不完全な探索を、実構造の分離証明として扱っていません。

旧QM9・SolQuestの選別済み別名キャッシュを、旧計画のSHA-256と照合しました。
各行のすべての別名を新予約と比較し、別名を複数系列へ分割していないことも全件検査しました。
PolyOmicsでは、周期系列によるつながりも保持しています。
予約に触れる行だけでなく、同じ接続系列の全行を除いて新しい候補集団を作りました。
元の特徴・Encoder入力・補助ターゲットを変更せず、元の行番号への対応を保存しています。

構造からの再計算は各資料で121–128行の決定的な検査と、HSP757行の全別名です。
大きい補助集団の全互変異性体を新たに再列挙したという主張はしていません。
大規模な比較は、以前に完全性を確認し、ハッシュで固定した別名キャッシュの全件検査です。
Abraham783行は今回も実構造から全別名を計算しました。

## 旧学習集団で見つかった重複

「新予約に重なる学習行」は直接別名が重なる行と、その接続系列の行を含みます。
高分子の計算行数を、独立した小分子や実測HSPの件数に換算しません。

| 資料・タスク | 旧学習行 | 新予約に重なる学習行 | 旧全候補から除く行・系列 |
| --- | ---: | ---: | ---: |
| QM9、6量子物性 | 61,622 | 7,469 | 7,897行・25系列 |
| SolQuest GDB17、39溶媒の計算溶媒和 | 97,619 | 1,370 | 1,957行・60系列 |
| SolQuest EGP、39溶媒の計算溶媒和 | 3,462 | 752 | 961行・101系列 |
| Abraham、E/S/A/B/Lの参照記述子 | 435 | 207 | 429行・167系列 |
| PolyOmics、MDの分散・電気の2項 | 17,833 | 1,671 | 3,599行・82系列 |

PolyOmicsの直接重複は学習1,654行・全候補3,582行です。
周期系列のつながりによって学習側へ17行を追加して除きました。
除外件数は学習・校正・テストを通した集団で、学習側の件数と足し合わせません。
別資料間の構造・系列の重複もあるため、資料ごとの行数を合計して独立化合物数とはしません。

## 新しい構造候補

旧予約・新しいHSP学習予約の両方を避け、全別名と接続系列を保持した候補です。
系列分割の種は42、校正を持つタスクでは追加の種43を維持しました。
各新分割の別名重複と、予約との別名重複は0です。

| 資料 | 新候補行・系列 | 新学習行・系列 | 新校正行・系列 | 新テスト行・系列 |
| --- | ---: | ---: | ---: | ---: |
| QM9 | 68,057・6,626 | 53,670・5,300 | なし | 14,387・1,326 |
| GDB17 | 157,421・77,298 | 95,787・46,378 | 31,137・15,460 | 30,497・15,460 |
| EGP | 4,583・581 | 1,075・348 | 1,984・116 | 1,524・117 |
| Abraham | 354・275 | 222・165 | 68・55 | 64・55 |
| PolyOmics | 26,867・10,204 | 15,940・6,122 | 5,308・2,041 | 5,619・2,041 |

QM9・GDB17・EGP・Abrahamは、この候補で行数と一意な構造数が一致します。
PolyOmicsは計算26,867行に対し末端付き特徴構造25,357種類、
学習15,940行に対し特徴構造15,045種類です。繰返し単位・DP・MD状態の違いを保持します。
EGPの行数が分割比率と大きく異なるのは、大小の系列をまとめて分割しているためです。
行数の均等化を理由に系列をばらしていません。

この監査自体は学習を実行していません。候補の選別は、新しい範囲の学習許可ではありません。
QM9ではまず53,670構造を実際に再学習できる候補として渡しました。
[後続の別レビューによる実再学習とQM9のHSP転移](expanded-hsp-auxiliary-refit.md)は完了しています。
本資料は、モデル学習前に凍結した構造監査の記録として残します。
別の固定計画とローカル学習レビューにより、特徴の前処理・回帰・残差・校正を学習側だけで作ります。
GDB17でも95,787構造を使える候補がありますが、EGP全骨格を避ける旧予約を維持します。
量子・計算溶媒和・参照記述子・MD・HSPの件数とラベル種を混ぜません。

## 再現記録と権利

元のQM9 Embeddingの全68,057行について、選別元とEncoder入力の一致を確認しました。
元配列のSHA-256を旧計画と照合し、全選別配列が有限であることを検査しています。
重み更新・再Embedding・外部モデルの追加取得はしていません。
実装の`chemistry.py`・`splitting.py`・`embargo.py`も別名・選別記録に結び付けました。
5資料の既存モデルについて、保存した再現検証と実際のモデル・計画の対応も確認しました。
旧検証での予約重複0を、新しい予約での重複0へ読み替えていません。
