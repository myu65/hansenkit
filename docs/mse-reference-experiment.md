# 757行への拡張と直接電子物性によるMSE比較

2026-10-12。対象は測定系譜が不明な`published_reference`です。
ユーザーが指定した目標は、変更していない1,013構造について、δD・δP・δHそれぞれの
点MSEを保存済みHSPiT比較値以下にすることです。独立実測の資格確認をこの数値目標の
達成条件にはしません。旧MAE基準とは別に集計します。
既に複数の実験で参照した評価集合なので、新しい盲検とは扱いません。

## 結果

主方式`combined`は、**1,013構造で3成分すべての点MSE目標を通過しました**。
全757学習行での最終選択は3成分とも`base`のmixed-physics kernel、α=0.1、γ=1.0でした。
固定した化学線形0.4＋全Embedding RBF0.4＋24列proxyのRBF0.2です。
`combined`と`base`の最終予測は同じです。直接xTB条件も目標を通過しますが、
主方式の選択は学習系列内の規則に従って保持しています。

MSEの単位はMPaです。3成分を平均して判定していません。

δD **+0.237994**、δP −3.945942、δH −3.087126 MPaです。

評価側の既存13件の参照規約矛盾も維持しています。
予測区間の校正、実測の温度・状態、独立した測定系譜、物理backendの資格は未確認です。

## 固定した計算と特徴

化学特徴105列と確認済みMoLFormer 10%版の固定Embedding768列を使用します。
旧51学習行と1,013評価行の特徴はビット単位で保持し、追加706行だけを同じ手順で計算しました。
原構造とGrouping別名を分け、encoderには元のcanonical構造を渡します。
重み更新、自動ダウンロード、遠隔モデルコードの実行はありません。

ETKDGv3とMMFF94の固定条件で3コンフォマーが全て揃う1,751構造について、
気相GFN2-xTBの単点計算を各3回、合計5,253回実行しました。
全プロセスが正常終了し、タイムアウト0、全出力が原子順・電荷・条件・単位検査を通過しました。
学習・評価合わせた1,770行中1,762行で電子物性が揃い、8構造は欠損のまま残しました。
8構造の理由は埋込み未完了3、MMFF電荷不備2、最適化未完了1、固定サイズ範囲外1、
MMFFパラメータなし1です。評価集合から除去せず、学習分割内の欠損処理を使います。

各単点は`--gfn 2 --chrg 0 --uhf 0 --acc 1.0 --iterations 250 --etemp 300
--norestart --input controls.inp --parallel 1`です。電子温度300 Kは液体の測定温度ではありません。
座標の再最適化、計算失敗後の再試行・設定変更・値の修正はありません。
1プロセス1スレッド、同時4プロセス、1コンフォマー120秒の上限を固定しました。
`XTBPATH`、空の`XTBHOME`、PATH、control、暗黙入力なしの条件を保存・独立確認しています。

[理論とxTB事前確認](computational-mse-strategy.md)に記したとおり、SCC結果のfull双極子と
最後のwavefunctionのfull／q-only双極子を区別します。α・C6・C8はD4の環境モデルによる
推定量です。HOMO–LUMO gap、部分電荷、等重みのコンフォマー平均・標準偏差、
幾何体積比、H結合サイトの電荷など20列を追加します。
これらを液体CED、実測分極率、水素結合強度、HSP3成分へ直接変換しません。

対照`base`には旧19個のRDKit proxyと5個の固定したMR・電荷・体積比があり、合計24列です。
`direct_xtb`は同じ24列に20電子特徴を足した44列です。
対照にも3D・電荷proxyがあるため、今回の差を「全ての計算化学の有無」とは説明しません。

## アーキテクチャと選択

[アーキテクチャ調査](mse-architecture-strategy.md)を受け、有限の加算kernelを実装しました。
化学線形、化学＋全Embedding線形、化学RBF＋学習内PCA8のEmbedding RBF、
化学線形＋全Embedding RBF＋物理特徴RBFの4テンプレートを使います。
kernel18設定、正のExtraTrees4設定、LightGBM4設定を各特徴条件で比較し、
学習平均を加えた全53候補です。新しい注意層の学習は行わず、MoLFormerの注意機構は固定です。

外側5系列分割、各外側学習分割の内側5系列分割で、成分別の系列平均MSEにより選びます。
最終757行でも同じ内側規則を適用してから再学習します。
`base`と`direct_xtb`は各条件内で選び、主方式`combined`は内側分割で全53候補から選びます。
外側成績や外部評価を見て成分別方式を組み直す手順はありません。
同点許容差1e-12、候補順、seed42、全hyperparameterは先に固定しました。

欠損補完、欠損mask、標準化、PCA、kernelのtrace正規化は各学習分割だけで推定します。
RBFのγは列数で割り、加算重みと正則化を事前固定します。
負の予測は切り詰めません。kernelの数値解は不確実性の校正や物理資格を与えません。
全1,770行の予測と成分別選択、モデルJSONの完全一致roundtripを固定してから、
元の評価キャッシュを開く手順です。

Gitへ入れません。MITは独自のparser・kernel・テスト・文書のライセンスです。

実binaryは`6.7.1pre (5071a88)`、2024-07-23 buildで、実commitは
`5071a8869720fb0ecd788af977159869b64a277c`です。release tagの
`26b28010e805f7d1aeeef39813feb473e69cc4be`とは分けて記録します。

main sourceはLGPL-3.0-or-later、JSON-FortranはBSD宣言がありますが、WindowsのD4版差、
Intel/static依存、数表の上流権利と商用再配布まで確認したものではありません。
[権利台帳](rights-ledger.md)の限定レビューを維持します。

公開の`block_kernels`はレビュー済み配列用の小さなAPI、`xtb_features`は既存出力のparserです。
どちらも既定の`HSPModel`やCLIへ物理backendとして接続しません。
高分子、EO/PO、イオン性分子、混合物の通常の数値推算は引き続き拒否します。
