# MDの固定構造応答をHSP補助特徴として比較する

17,833計算行で学習した[PolyOmicsのA/B/Cモデル](periodic-cohesion-learning.md)を
再学習せずに使い、構造応答を2次元の補助特徴へ投影しました。
同じ11件の公開HSP参照値で3方式を学習し、同じ1,013構造を比較しました。
δDは全方式で悪化し、3成分の非劣性は全方式で未達でした。
モデルを既定の推算へ採用せず、否定的な結果も保持しています。

今回、新しいHSP正解や実測化合物は増えていません。
既存の17,833行を再び学習した、またはHSP3成分の学習行として数えたわけではありません。
高分子・EO/PO・イオン・混合物への通常の推算は引き続き拒否します。

## 転移する量の定義

MDの元モデルは、末端付き1単位の105化学特徴、または768次元の固定MoLFormerに、
DP・全鎖質量・DPの逆数・atactic表示の4条件を加えて学習しています。
その出力は300 K・1 atm・GAFF2_modの分散項と電気項です。
小分子に鎖条件を推測して与えたり、電気項をδP/δHへ分けたりする根拠はありません。

今回は各保存ヘッドについて、構造座標だけの中心化応答を求めました。

```text
response = ((structure_features - train_mean_structure) / train_scale_structure)
           @ frozen_coefficients_structure.T
```

切片と4鎖条件の寄与を外します。CではAの化学応答と残差ヘッドの構造応答を足します。
全鎖質量・DP・立体の仮定を新たに置かず、モデル状態も変更しません。
これは構造が学習済みの2出力へ与える数理的な応答で、絶対的な凝集物性やHSPの予測値ではありません。
負の応答も特徴としてそのまま保持し、物理量として採用しません。

105化学特徴に各方式の2応答を加えた107特徴から、Ridge alpha 100で3成分を学習しました。
A応答は元の化学特徴の線形結合なので、Aに新しい構造情報を加えません。
追加座標はRidgeの実効的な正則化を変える比較でもあります。
B/C応答には既存Embeddingの低次元投影が加わります。
全方式を固定して比較し、テスト誤差を見て投影・方式・正則化を選び直していません。

## 予約・権利・評価条件

- HSP予約は1,266同一性・132骨格・2,798別名を維持。
  MDの学習17,833行の保存別名と、この予約の重なりは0です。
- HSPの学習は従来の11構造・10系列だけ。比較は1,013構造・68系列。
  HSPの学習・比較の別名の重なりも0です。
- HSPiT/MathieuのExcel正解・係数・計算出力を、特徴・学習・調整へ使っていません。
  既存HSPiT計算との比較は、予測を固定した後の評価だけです。
- MDは `computed_md_cohesion`、HSPは `published_reference`。
  参照値の個別測定由来・温度・相・立体は未資格で、過去にも探索した集団です。
  ブラインドの独立実測テストとは呼びません。
- 元の準備・学習レビューは変更せず、今回の固定応答利用と11参照値の学習を
  別のハッシュ付きローカルレビューで許可しました。
  利用監査の通過はユーザーの仮定 `operator_assumption` として記録しています。
- 源データは[著者の固定PolyOmics版](https://huggingface.co/datasets/yhayashi1986/PolyOmics/tree/041e5834ea1a48682fae12dc39ccd723bcd4f771)、
  宣言ライセンスはCC BY 4.0。原表・Embedding・構造・重み・予測配列はGitへ入れません。
  MoLFormerは従来の[確認済み10%版](molformer-review.md)を維持し、再実行・再学習していません。

## 1,013構造での結果

単位はMPa^0.5。MAE / RMSE / R²です。

| 方式 | δD | δP | δH |
| --- | --- | --- | --- |
| 固定した従来A | 1.435 / 1.782 / -0.053 | 2.730 / 3.604 / 0.282 | 3.295 / 4.654 / 0.099 |
| A＋MD-A応答 | 1.449 / 1.844 / -0.128 | 2.793 / 3.680 / 0.251 | 3.279 / 4.696 / 0.082 |
| A＋MD-B応答 | 1.493 / 1.843 / -0.127 | 2.673 / 3.521 / 0.314 | 3.247 / 4.584 / 0.126 |
| A＋MD-C応答 | 1.455 / 1.842 / -0.126 | 2.746 / 3.608 / 0.280 | 3.254 / 4.631 / 0.108 |
| 同じ行のHSPiT比較値 | 0.979 / 1.336 / 0.408 | 2.818 / 4.103 / 0.068 | 2.411 / 3.704 / 0.429 |

事前基準は、各成分の点MAE比が1.10以下、系列ブートストラップによるMAE差の
片側95%上限が0.30以下です。68系列・2,000回・固定シードで評価しました。

| 方式 | 点MAE比 D/P/H | MAE差の95%上限 D/P/H | 通過成分 |
| --- | --- | --- | --- |
| A＋MD-A応答 | 1.481 / 0.991 / 1.360 | 0.598 / 0.322 / 1.367 | なし |
| A＋MD-B応答 | 1.526 / 0.949 / 1.347 | 0.688 / 0.269 / 1.344 | Pのみ |
| A＋MD-C応答 | 1.487 / 0.974 / 1.350 | 0.612 / 0.303 / 1.363 | なし |

B応答の追加で従来Aに対するδP MAEは約2.1%、δHは約1.4%下がりましたが、
δDは約4.0%悪化しました。全成分を改善したという結果ではありません。
負のP/H予測数はA応答が3/5、B応答が2/2、C応答が2/3。Dは全方式0です。
誤差を良く見せるための切り上げや、誤差に基づく比較行の除外をしていません。

## 外挿と固定ヘッドの数値検証

MDの学習に使った105構造座標の範囲外は898/1,013行。
範囲内の115行も、300 Kの周期材料から小分子HSPへの物理的な適用資格を証明しません。
107特徴のHSP学習範囲外はA/B/C応答が970/983/975行です。
全体・範囲外・範囲内を別集計し、範囲内だけに評価対象を縮めていません。
MDの校正区間をHSPへ転用せず、HSPの校正済み区間も主張しません。

別プロセスで1,030構造の105特徴を再計算し、全投影を、元の完全なアフィンモデルに
学習平均の条件座標を与え切片を引く別計算で照合しました。
107特徴の全3ヘッドをNumPyの双対正規方程式で再構成し、1,013行の予測最大差は
7.99×10⁻¹⁵。指標・負値・外挿・系列ブートストラップも一致しました。
元のMDモデル、HSP特徴・学習値、分割、予測配列のハッシュは変わっていません。

以前のCPU/GPU Embedding照合で、1座標が1e-4許容差を超えた失敗は保持します。
今回は再抽出せず、各入力座標の差が1.1e-4以内という条件付きで、
固定したMD投影とHSPヘッドを通じた変化の上限を求めました。
各出力の符号に合わせた入力摂動でも上限を照合し、全成分の基準判定が安定すると確認しました。
最大上限はB応答のPで0.001960。これは再学習・再選択や元の許容差失敗の修復を証明しません。

## 次の実験

周期材料の計算2項を2座標へ圧縮して追加する今回の方法では、δDの改善を得られませんでした。
同じ参照テストの結果に合わせてさらに投影を探索する前に、温度・分子構造・測定方法を
確認できる小分子の校正資料、または小分子液体の計算条件を揃えた物理データが必要です。
δP/δHの分離と、高分子のMn・末端・EO/PO分布の実測検証も別途残っています。
