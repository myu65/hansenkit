# MSE比較に向けた参照データの構造照合

2026-10-11、前回未照合だったKouTerの候補をまとめて照合し、追加706参照行の
構造を確認しました。既存51行と合わせた学習候補は757行・746構造・402系列です。
この調査では数値の採用、特徴抽出、学習、HSP評価キャッシュの読込みを行っていません。
追加値は測定系譜が未確認の`published_reference`候補で、独立実測件数に足しません。

## 固定した資料と照合方法

[KouTerの著者リポジトリ](https://github.com/benkour/KouTer/tree/f60e5237d2ca51ad03675829bc1ff56f1afd0235)
の固定CSVを使いました。[一次論文](https://doi.org/10.1038/s41598-026-72415-z)は
Hansen成分の単位をMPa^0.5と宣言し、主な出典をハンドブック等として記載します。
CSVの行ごとの測定法・推算法、温度、試料状態、上流数表の再利用条件は未確認です。
記事のCC BY 4.0を元表の利用許諾と同一視しません。

元CSVは10,487行で、以前の[構造検査](reference-data-expansion.md)を通った
964行・959 CASを対象にしました。[PubChem Identifier Exchangeの公式手順](https://pubchem.ncbi.nlm.nih.gov/idexchange/idexchange-help.html)
に従い、Same CIDからSMILESへ変換する入力・出力対応のバッチを送りました。
親化合物化、成分分割、立体を外した一致検索は指定していません。
送ったのは公開CASだけで、HSP値・会社データ・モデル重みは送っていません。
保存済みの公式XML雛形から入力を置き換え、[PUGの公式API](https://pubchem.ncbi.nlm.nih.gov/docs/power-user-gateway)
を使いました。前回の個別照会で続いたHTTP 503を、未照合行の採用理由にはしていません。

959 CASすべてに対応が返り、複数候補を含む1,036対応を保存しました。
元の構造と返却構造を同じ規則で正規化し、立体を含むcanonical SMILESが
一意に完全一致した行だけを候補として残しました。

| 判定 | 元CSVの行数 |
| --- | ---: |
| 一意な立体構造が完全一致 | 739 |
| 立体指定の違い | 141 |
| 結合構造または互変異性体の違い | 51 |
| 同一CASから複数の異なる立体構造 | 16 |
| 有効な構造が返らない | 17 |
| 合計 | 964 |

不一致行の元SMILESをPubChemの構造へ置き換えていません。
完全一致の739行・731構造・390系列には、既に学習した33行を含みます。
新しい候補は706行・700構造です。既存51行とのcanonical構造一致が4行あるため、
結合後は757行・746構造になります。11構造に各2参照行があり、
値の一致・不一致はこの構造照合では調べず、平均や削除もしていません。
同一構造の全行は同じ系列に残します。

## 予約、サイズ、Encoderの確認

全評価予約1,266構造・132旧骨格・2,798別名を元ファイルから再構成しました。
旧Murckoの予約と、保守的なcore、完全な範囲内の互変異性体の別名を保持しています。
新706行と全予約の別名重複は0です。既存51行を含む候補全体と、
従来の1,013評価構造・2,206別名との重複も0です。
既存51行の順序が以前の特徴キャッシュの先頭51行と一致することを、
SMILES列だけを読んで別に確認しました。学習対象や評価対象を数値から選んでいません。

候補全体は単一の結合グラフで、重原子数の最大は36、分子量の最大は495.639 g/molです。
742行は形式電荷なし、15行は既存規則が認める中性共有結合のnitro/nitrateです。
同位体・ラジカルはありません。元の60重原子・500 g/molの上限とEO/PO鎖の
除外を保持し、電荷を消す操作や通常のHSP推算の適用範囲変更は行っていません。

確認済みMoLFormerのローカルTokenizerとconfigだけを読んで、
757行の入力を切り詰めずに検査しました。最大67 tokensで、上限202以下、
未知tokenは0行でした。重み・外部モデルコードは読み込んだり実行したりしていません。
構造別名は系列分割にだけ使い、Encoderの入力に置き換えません。
Encoder内部の既存のcanonical nonisomeric前処理は変更しません。

補助学習を再利用する際は、旧HSP予約にこの学習候補全体も加え、
各補助モデルの学習・校正・評価群を再監査する必要があります。
衝突した過去の学習は、補助評価行だけを除いて修復したことにせず、再学習します。

## ローカル成果物と採用手順

原資料と構造対応は無視対象の`local/mse-data-expansion-v1/`に保存しています。
公開するのは独自の集計と説明だけです。主なSHA-256は次の通りです。

| 成果物 | SHA-256 |
| --- | --- |
| 固定元CSV | `3c6adc6381d305ff094e60d37e98791ec409b4aadb7bddb69574d272a3934d51` |
| 元の全HSP予約 | `41e4bc755b3ad79e1b4ab50765c380aeed4ef6799709692c0c6bd7b5b5c13c82` |
| 入力・SMILES対応 | `1961bcbe35802072299d0fbc26a56ef6c69f7e113d9928b00d5e6c182e0d3913` |
| `identity-audit.local-only.json` | `72ec137450f911b89f4320020b794b077a21b13dc64dd698fcfa08ea8b0460f2` |
| `combined-cohort-audit.local-only.json` | `eceae74fc9e10917a13e6d7cffa8ed752abb366d513b9f480b557e253c399e04` |
| `prior-order-verification.local-only.json` | `6b817cb4ea0f1ca9d071b8d8ea71dbe25336b2444a4c908ed8ad319a6eab8123` |

元CSVのローカル保存先は
`local/source-renewal-v1/kouter2026-hansen.csv`です。
`combined-cohort-audit.local-only.json`の
`additional_source_row_indices_in_source_order`に、新706行の0始まりのデータ行番号を
元CSV順で保存しました。ヘッダーは行番号に含めません。
`additional_identity_candidates_in_source_order`は構造・CAS・別名・根拠の対応、
`combined_identity_and_group_order`は既存51行を先頭に置いた全757行の順序と系列です。
`identity-audit.local-only.json`は全964行の成功・失敗とPubChem対応を保存します。
表やキャッシュのハッシュ、原51行の順序、全予約、Tokenizerの根拠を検証してから使います。

準備成果物の`training_allowed=false`はそのままです。数値を読む前に、
この正確な部分集合と候補順・単位・モデル候補・系列内MSE選択を凍結し、
別のハッシュ付きローカル学習レビューを作ります。ユーザーの監査通過の仮定は
`audit_basis="operator_assumption"`、用途は科学研究・私用・非商用と記録します。
数表、特徴配列、予測配列、派生重みを公開する許可にはしません。
温度・状態を推測で298.15 Kや液体へ補完せず、測定系譜は未知のまま保存します。

HSPiT Excelは評価専用です。そのラベル・係数、公開教師モデルの予測値、
参照GCの出力を、今回の学習・特徴・補助目標・選択・校正には使いません。
1,013構造の比較は既に探索した公開参照ベンチマークです。
各成分のMSEが既存法以下になっても、新しい盲検や独立実測精度とは呼びません。

### 別レビューで採用した757行の独立照合

構造候補の準備後、別の固定したローカルレビューで706行の数値読込みと
構造特徴の抽出を許可しました。独立した照合スクリプトは、特徴作成・学習関数を
呼ばずに原51行と指定706行を読み、全757行の記録・NPZの3成分・列順・構造順を
元資料と完全一致で確認しました。指定以外の元CSVのHSP数値は読んでいません。
旧51行の記録・数値と、旧学習／評価構造の化学特徴・Embedding・評価系列も不変でした。
評価のHSP数値キャッシュは開かず、学習は実行していません。

同一構造の11組すべてが、各3成分に異なる参照値を持っていました。
数値の完全一致による分類で、物理的に有意な差や誤りとは断定しません。
全行を平均・除外せず同じ系列に保持しました。
新706行と全2,798予約別名の重複は0、全757行と1,013評価構造の別名重複も0です。
元51行のうち11行は、既存の限定レビューで許可された元HSP学習行として残しています。
この11行は補助学習用の全HSP予約に含まれるため、
「全757行が全HSP予約の外」とは主張しません。

MPa^0.5とδD/δP/δHの対応は、ハッシュで固定した特徴計画と元列名から照合しました。
新しい行記録ファイル単体は単位を繰り返していないため、計画と特徴レシートを
合わせて読む必要があります。未知の温度・状態、`published_reference`、
`operator_assumption`、科学研究・私用・非商用、非再配布の条件は復元後も維持しています。
独立照合レシートは`local/mse-data-expansion-v1/independent-adoption-verification.local-only.json`
に保存し、原データ・特徴・重みは公開しません。

DES370KとSPICEの配布元メタデータは別々に取得し、ハッシュとファイル名・サイズを

実装は取得せず、これらによる追加学習も行っていません。
まず今回の746構造候補の系列内検証を実施し、必要な補助目標と取得量を固定してから
新しい資産を準備します。量子補助・参照記述子・HSP参照の件数は各々分けて報告します。
