# 学習系列だけで正則化を選ぶHSP参照実験

回帰のalphaを100で固定した[前の参照実験](current-hsp-fewshot.md)に対し、
学習側の11件・10系列だけで設定を選び直すアルゴリズムを固定して比較しました。
一部のδH誤差は小さくなりましたがδPは悪化し、1,013構造で全3成分の非劣性は未達です。
同じ参照集団の誤差を以前から見ているため、新しい盲検や独立実測の精度証明とは扱いません。
既定のHSP予測・適用範囲・不確実性を変更せず、テストを見て再選択もしません。

## 配列用の選択関数

`hansenkit.selection.fit_group_selected_ridge(x, y, groups)`を追加しました。
入力は使用許可と評価予約を確認済みの**学習分割だけ**です。
系列キーは事前に正規化・同一性・互変異性体・骨格の別名を統合した文字列または整数です。
この関数自体は化学構造や権利を確認できず、単に行番号を系列キーにしても独立性を作れません。
通常の学習・CLIへ自動で有効化はしません。戻り値も、資格確認済みHSPModelではなく線形ヘッドです。

候補は学習平均とRidge alpha 0.01/0.1/1/10/100/1,000/10,000です。
最大5つのGroupKFold、seed 42で、各検証系列のMAEを等しく平均して成分ごとに選びます。
各スケーラーと回帰は、その分割の学習群だけから求めます。
同点を1e−12以内とし、平均値、その後に大きいalphaを優先します。
全候補・成分別スコア・選択値・分割を返し、最終ヘッドは渡された学習行全体で作ります。
選択スコアは、そのヘッドの独立テスト精度でも校正区間でもありません。
3系列未満、不正な行列・系列キー・alphaは拒否します。

## 固定したHSP実験

新計画SHA-256: `bc9fbf3e2165a3072663ac85f6aa09c20420c1cd63b059d717f4ee7bc1037a05`。
出典、11学習構造、1,013テスト構造、現在と旧Excel予約、68テスト系列を維持しました。
原HSP参照値の測定系譜・温度・立体・材料状態は未確定なので、ラベルは`published_reference`です。
補助QM9の61,622学習分子を、11件のHSP学習正解に足して数えません。
ソースと以前の特徴・予測・分割をハッシュで固定し、別のローカル許可を記録しています。
Excel数値、係数、GC比較値、疑似ラベルは選択・学習に使いません。

Aは105化学特徴、Bは確認済み固定MoLFormerの768次元、A＋QM9は111特徴です。
選ばれたalphaはAとA＋QM9が3成分とも10、Bが3成分とも0.01でした。
この選択にテストラベルは使いません。モデルと予測のハッシュを固定してから評価値を読みます。

Cは、学習側の10系列を一群ずつ外して、ハイブリッド全体の検証MAEで残差設定を選びます。
その外側学習群の中でAの設定を選び、残差用のA予測を作るときも、さらに一系列を外して
残る行だけでAの設定を選びます。外側の検証ラベルは、残差を作る選択・回帰に入りません。
検証系列を含んで作った残差を事前計算し、残差のCVへ渡す処理はしていません。
10外側分割、90残差分割、55個の異なるA学習部分集合を記録しました。
候補は残差なし、学習残差平均、同じRidgeグリッドです。
選択結果はδD/δHが残差なし、δPがalpha 10,000です。
最後に全11件のAと、系列を外して作った残差から最終ヘッドを作りました。

## 結果

単位はMPa^0.5。同じ1,013構造の探索済み参照評価です。

| 方式 | δD MAE / RMSE / R² | δP MAE / RMSE / R² | δH MAE / RMSE / R² |
| --- | --- | --- | --- |
| A 学習内選択 | 1.427 / 1.934 / -0.240 | 3.379 / 4.523 / -0.132 | 3.189 / 4.537 / 0.143 |
| B 学習内選択 | 1.345 / 1.638 / 0.110 | 3.008 / 4.057 / 0.089 | 3.719 / 5.149 / -0.103 |
| C 入れ子で選択 | 1.427 / 1.934 / -0.240 | 3.466 / 4.636 / -0.189 | 3.189 / 4.537 / 0.143 |
| A＋QM9 学習内選択 | 1.429 / 1.906 / -0.204 | 2.955 / 3.913 / 0.153 | 3.146 / 4.558 / 0.135 |
| 保存済みHSPiT比較値 | 0.979 / 1.336 / 0.408 | 2.818 / 4.103 / 0.068 | 2.411 / 3.704 / 0.429 |

A＋QM9のδH MAEは固定alphaの3.330から3.146へ小さくなりましたが、δPは2.589から2.955へ悪化しました。
CのδPも固定設定の2.717から3.466へ悪化しました。改善した成分だけで採用しません。
以前と同じ各成分MAE比1.10以下・系列ブートストラップの差の片側95%上限0.30以下を使い、
A＋QM9のδPだけが通過しました。全方式でδD/δHが未通過、全3成分の非劣性は未達です。
13構造に異なる参照値が複数ある元データの制約も保持し、評価対象の再除外はしていません。

学習特徴の範囲外は969件、範囲内は44件です。範囲内44件だけへ目標を縮めません。
負のδP/δHはAが67/19件、Bが0/0件、Cが90/19件、A＋QM9が36/11件でした。
切り上げず、生の研究結果として記録しました。独立した校正群や物理推算の資格はありません。
少数の学習系列で選んだ設定は、この外挿集団へ一般化できていません。

## 検証と保持した失敗

NumPyの双対正規方程式で、全候補の分割内回帰・標準化・系列平均MAEと選択を独立に再計算しました。
55部分集合、10外側・90残差分割、保存ヘッドと全1,013予測、3成分指標、OOD、
2,000回の系列ブートストラップを照合し、最大予測差は7.11×10⁻¹⁵でした。

以前の全1,030構造のCPU/GPU MoLFormer再計算を、同じ特徴と量子ヘッドのハッシュで参照しました。
保存ヘッドを固定し、そのアフィン係数と記録した最大Embedding差1.08×10⁻⁴から、
入力差による予測・MAE・ブートストラップ分位点の変化の上界を求めました。最大はA＋QM9のδPで0.00703。
この固定ヘッドの上界を使っても全成分の元の合否が変わらないことを確認しています。
CPU特徴での再学習・設定の再選択まで確認したという意味ではありません。
今回エンコーダを再実行したとはせず、以前の絶対許容差1e−4の失敗も合格へ読み替えません。

初回は既存の整数系列キーを文字列専用の検証で拒否しました。モデルができる前の失敗を保存し、
文字列・整数に対応してテストした新しいv2計画を固定しました。
次に学習後のキャッシュ保存でNumPy整数のJSON変換に失敗しました。
保存済みモデルを変更せず、失われた55キャッシュを復元し、元の選択スコアとハイブリッド候補を照合しました。
予測の固定はこの復元後、評価値を読む前に行っています。

13個の追加テストで系列内の前処理、偏った系列サイズのMAE、定数候補、成分別選択、
整数系列キー、再読込み、不正入力を検証しています。外部重みや学習済み状態はGitに含めません。
既存Excelとは別の測定系譜・条件を持つHSP学習群と新しい評価群の確保は、引き続き必要です。
