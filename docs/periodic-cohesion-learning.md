# 周期系列を分けた凝集物性の学習

PolyOmicsの計算値を使い、分散項 `sp_vdw` と電気項 `sp_ele` の2項を
ローカルでA/B/C学習しました。学習17,833行、テスト6,937行です。
電気項は√(δP²＋δH²)に対応する合計で、δP・δHの別々の正解ではありません。
HSP3成分の学習正解を増やしたという扱いはしません。
既定のHSP予測の適用範囲、物理バックエンドの資格、公開重みの許可も広げません。

## 材料と源データの確認

[準備した71,848行](md-cohesion.md)から、旧来の予約・未確定判定40,592行、
エネルギー平均の診断フラグ6行、未確認の末端処理・立体規則194行、
特徴構造・予約別名等を確認できない590行を除き、30,466行を選別しました。
繰返し単位文字列は28,656種類、特徴に使う末端付き構造は28,646種類です。
これらを10,286系列へまとめました。計算行数を独立した実測化合物数とは数えません。
独立した検証でも、全30,466行の出典・観測値・鎖条件・系列を照合し、
残基質量と2末端の質量を直接足す別の方法でMnとの一致を確認しました。

著者公開データの版は `041e5834ea1a48682fae12dc39ccd723bcd4f771`。
入力CSVのSHA-256は `71e955ac1e90574ad009ccbf1238e595cf42905f3e600523ba2a6ea65c350213`。
温度300 K、圧力1 atm、GAFF2_mod、計算項の版0.1.1に限定した計算参照タスクです。
[一次論文](https://arxiv.org/pdf/2511.11626v1)のMD定義を使い、独立実測や
過去の全実行環境を再現したという主張はしません。

第1末端は全候補で `*C`。第2末端の空欄について、次の実際の旧版ソースで
未指定なら第1末端を使う規則を確認しました。

| ソースの版 | 固定したコミット |
| --- | --- |
| 0.2.10 | [956877f1](https://github.com/RadonPy/RadonPy/blob/956877f1c1be6098dd85c796786d6fadcdba878e/radonpy/core/poly.py) |
| 0.2.9 | [ca9052a4](https://github.com/RadonPy/RadonPy/blob/ca9052a42b29774cd73bc56a6d4311b865287d11/radonpy/core/poly.py) |

このデータ固有の規則として両端メチルを適用し、1/2単位の構造から求めた残基質量と
整数DPによる全鎖質量が、記録されたMn・Mwと一致することを全選別行で確認しました。
事前許容差0.05 g/molに対し、最大差は2.55×10⁻¹¹ g/mol。
元の準備ファイルの空欄・許可フラグは変更していません。
ここで確かめたのは、公開された計算プロトコル・構造・質量の対応です。
実験材料の末端、相、結晶性や過去の実行コード全体を保証するものではありません。
別の入力へ無条件で同じ末端規則を使うこともありません。

中性・同位体なしの単一二端構造、単分散の整数DP、`none/atactic` の立体規則を対象にしました。
5,119行は独自官能基語彙のカバレッジが1未満ですが、明示した元素・記述子を使い、
未割当の原子比率を特徴として記録します。未知のHSP基団係数を補ったわけではなく、
これらを通常のHSP推算へ通すこともありません。

## 周期構造の系列キー

`hansenkit.periodic.periodic_topology_alias` は、単位の切り方・向き・複数単位を
まとめた表記による分割間の混入を防ぐ、独自のグループ用関数です。
既存の分子同一性・骨格・保守的な位相・完全な互変異性体の別名と併用し、
元のつながりを維持します。分子特徴・Embeddingの入力をこのキーへ置き換えません。

二つのポートを取り除いた実原子のグラフへ、隣接単位につながる仮想辺を付けます。
同じ原子へ戻る辺や平行辺も両端の隣接として数えます。
元素と重原子の隣接数から始め、8回の隣接ラベル更新を行い、ラベルの出現比率を
整数の最大公約数で規格化してハッシュにします。
この比率は周期単位を繰り返して表記しても変わりません。

| 表記例 | 同じ系列へまとめる例 |
| --- | --- |
| 単位の切り直し | `*CCO*`, `*COC*`, `*OCC*` |
| 複数単位の表記 | `*CO*`, `*COCO*`, `*COCOCOCOCOCOCO*` |
| 端の向き | `[1*]CC(C)[2*]`, `[2*]C(C)C[1*]` |

グループ用キーでは結合次数・プロトン配置・電荷・同位体・立体を無視し、
似たグラフが同じキーになる場合は保守的に同じ系列へまとめます。
厳密な分子同一性判定や化学量の特徴としては使いません。
元素と枝分かれの違い、切り方・向き・複数単位表記・同位体の扱い、
不正なポート・不連結・過大なグラフの拒否をテストしました。
512原子・8,192文字までのグラフを扱い、巨大な鎖は組み立てません。

## 固定した学習条件と結果

同一性・系列・周期キーの接続成分を作ってから60/20/20%の系列分割を行いました。
学習・校正・テストの別名の重なりは0です。

| 分割 | 計算行 | 系列 | 特徴構造 |
| --- | ---: | ---: | ---: |
| 学習 | 17,833 | 6,171 | 16,730 |
| 校正 | 5,696 | 2,057 | 5,409 |
| テスト | 6,937 | 2,058 | 6,507 |

Aは末端付き1単位の既存105特徴に、DP・構造から求めた全鎖質量の対数、
DPの逆数、atacticの表示を加えた109特徴。
Bは固定MoLFormer 768次元と同じ鎖条件4特徴。
Cは4分割で系列を分けて作ったAの残差をBの表現で補正します。
全方式でRidge alpha 100。学習中の同じ特徴構造の出現数の逆数で重み付けし、
残差学習の各内側分割でも、その分割の学習行だけから重みと標準化を求めます。
定数比較も学習データだけの重み付き平均です。

固定MoLFormerは確認済みの同じ版を使い、28,646種類すべてを切り詰めなしで抽出できました。
RTX 2080 Tiの当該プロセスのメモリ枠を12%に制限して実行し、約221秒、
最大予約量212 MiB。RTX 3060の既存処理は操作していません。
これはEmbedding計算で、GPU-MDを実行したという意味ではありません。
エンコーダは再学習せず、外部重みをGitへ入れてもいません。

単位はMPa^0.5。MDの2項についてのテスト結果です。

| 方式 | 分散 MAE / RMSE / R² | 電気 MAE / RMSE / R² |
| --- | --- | --- |
| A 化学＋鎖条件 | 0.938 / 1.296 / 0.553 | 0.750 / 1.138 / 0.842 |
| B 固定MoLFormer＋鎖条件 | 0.611 / 0.846 / 0.810 | 0.678 / 1.064 / 0.862 |
| C 残差ハイブリッド | 0.634 / 0.869 / 0.799 | 0.596 / 0.979 / 0.883 |
| 学習だけの定数 | 1.475 / 1.947 / -0.009 | 2.233 / 2.861 / -0.001 |

Bの分散MAEはAより34.8%低く、Cの電気MAEはAより20.6%低い結果でした。
Cが両項でBを上回るとは言いません。テスト結果を見て方式やパラメータを選び直していません。
2項同時の90%系列区間被覆率はA/B/Cが0.904/0.898/0.901。
半幅は分散が2.157/1.440/1.454、電気が3.644/2.433/2.457と広い区間です。
特徴座標の学習範囲外は14行ですが、全テスト系列は学習に含まれません。
座標範囲内であることだけで材料の適用を保証しません。

生の回帰結果では、電気項が負のテスト予測がA/B/Cで23/35/25行ありました。
誤差を良く見せるためのゼロへの切り上げは行わず、件数を報告します。
その数値を物理値として採用することもありません。
独立プロセスで保存モデルの全予測・指標・OOD・区間・被覆率と、
学習重み・標準化・4分割残差の再学習結果を確認しました。
材料検証の初回は、NPZの全配列を行ごとに読み直す不備で処理が長引いたため停止しました。
初回のコードと停止記録を残し、一度だけ配列を読み込む方法へ修正して全件を再検証しました。
この修正では入力データ・特徴・学習済みモデルを変更していません。

## 残る目標と権利

データ・特徴・Embedding・分割・計画のハッシュを別のローカル学習レビューで固定しました。
利用監査の通過はユーザーの仮定として記録し、元の準備ファイルの学習許可は無効のまま保持します。
係数表、原データ、構造・予測・特徴配列、MD由来モデル状態を公開しません。
公開物は独自の系列キー、テスト、方法と集計の文書です。

この実験は1万行以上の物理計算データを実際に学習しましたが、HSP3成分の独立実測学習ではありません。
δP/δHを個別に校正できる資料、1,000化合物での既存手法との比較、
高分子・長鎖界面活性剤の物理HSP推算の資格は引き続き必要です。
一つの力場・温度・材料状態での計算参照精度を、実物のHSP精度や別の状態へ置き換えません。
