# 二量体相互作用データの構造監査

2026-10-12にDES15KとHB300SPX×10をローカルへ取得し、両方のモノマーを現在のHSP予約と照合しました。
DES15Kで残ったのは同種二量体1組の4配置・1系列です。HB300SPXには採用できる系列がありませんでした。
今回は学習を行わず、HSP教師化合物も増えていません。水素結合の補助学習に必要な系列数を得るために
予約を緩めることはしません。

## 予約と権利の範囲

旧2,798別名をすべて保持し、[757行のHSP学習](mse-reference-experiment.md)に使う
746個の実際のcanonical構造の別名を加えました。共有した固定snapshotは5,176別名、
2,001個の予約構造、632個のlegacy Murcko scaffoldです。
canonical identity、legacy Murcko、保守的なcore topology、完全に終了した有界互変異性体の別名を
照合します。各二量体の両モノマーが予約の外にある必要があります。
元11行のHSP学習に対する限定例外を補助学習へ流用しません。

追加集団から人工的に裸のMurcko scaffoldを作って`HoldoutEmbargo`を再構成すると、
その派生scaffoldの1つで有界互変異性体列挙が終了しませんでした。
失敗を記録し、公開のconstructorや列挙上限を変更していません。
実際のHSP原構造はすべて完全な列挙を終えています。
今回使うsnapshotは旧予約とその実際の原構造の完全な別名の和で、
人工scaffoldの途中結果を採用しません。Grouping別名をモノマーの化学構造へ置き換えません。

取得、構造解析、源資料の数値を読む範囲は資産・script・予約hashを先に固定しました。
`audit_basis="operator_assumption"`、科学研究・私用・非商用のローカル用途です。
Excelの数値・係数やHSP評価キャッシュを読まず、特徴・学習・設定選択・校正へ入れません。
源データ、構造対応、座標、源エネルギー、外部数表とモデルをGitへ含めません。

## DES15K

[著者のFigshare資産v1](https://doi.org/10.6084/m9.figshare.12692717.v1)のfile `24032201`、
CSV 13,139,993 bytesを取得し、配布元のMD5 `d6c564d0b4ceda7f809ed737853866cf`と一致しました。
SHA-256は`f90a8da6cb12e290d2cd3590b9a19e739b4f302c15b9f06d0a2c3a5d2f91b0b0`です。
[固定版API](https://api.figshare.com/v2/articles/12692717/versions/1)はこの資産にCC0を宣言します。

単位と列の意味は[一次論文](https://doi.org/10.1038/s41597-021-00833-x)の補足Table S2と、
[著者の別配布](https://zenodo.org/records/5676220)にある`DES15K_meta.csv`を照合しました。
後者は13,021,309 bytesのZIPでMD5 `a64a4c279c376ecfea242c49aea37c87`を確認し、
metadata、README、LICENSEだけを展開しています。別ZIPの数値データ本体は読みません。
このZenodoの表示はCC BY 4.0ですが、同梱LICENSEには著者の独自のnotice保持・非推奨条件付きの
再利用許諾があります。FigshareのCC0、Zenodo表示、同梱条件を一つの許諾へ統合せず記録しました。
単位を確認するための別資産の許諾を元CSVへ移していません。公開再配布は今回の許可対象外です。

| 実際のCSV監査 | 件数 |
| --- | ---: |
| 幾何配置行 | 14,651 |
| canonicalモノマー | 159 |
| 順序を無視したcanonical pair／源system ID | 3,052 |
| モノマーの系列 | 23 |
| 源geometry group | 4,981 |
| QM最適化由来の配置 | 12,183 |
| MD由来の配置 | 2,468 |
| 少なくとも片方のモノマーが予約と衝突 | 14,647 |
| 両方のモノマーが外にある配置 | 4 |

源SMILESを正規化し、原形式電荷、明示水素を含む原子数、両モノマーに対応する元素組成、
座標の長さと有限性を全行で照合しました。電荷・原子数／組成・座標形式の不一致は0です。
源geometry IDは14,651個で重複0です。22個のモノマーはイオン・未確認の電荷／断片のクラスに
該当し、4,388行にはそのようなモノマーが含まれます。予約との衝突と数が重なるため加算しません。

CCSD(T)/CBS、HF、MP2、SAPT0などの電子相互作用列と、`nn_*`のSNS-MP2予測を分けます。
計算値は`computed_auxiliary`、予測列は別のteacher補助値で、同じ計算教師として数えません。
今回確認した量子計算列は全行で有限です。SNS-MP2の3列はそれぞれ14,265行が有限、386行が欠損で、
欠損を量子計算列で埋めません。DES5Mを取得して量子計算件数へ混ぜる処理もありません。

エネルギー列の単位はkcal/mol、座標はangstrom、電荷はelementary chargeです。
`espx_HF_ovl`と`espx_MP2_ovl`は密度行列overlapで単位がなく、エネルギー扱いしません。
`cc_basis`は計算条件で、数値特徴に自動符号化していません。
補足Table S2と著者metadataの`SAPT total`説明には一次exchange項`sapt_ex`がありません。
記載式をそのまま合計すると源`SAPT total`との最大差は274.3342 kcal/molでした。
exchange項も含める計算では最大差3.0e-5 kcal/molとなり、出力の丸め幅と整合します。
これは説明式の欠落を示す照合結果で、源値を修正していません。
他のHF／MP2／CCSD(T)／CBSの加算・差分関係の最大差は2.0e-5 kcal/molです。
別のheadへ分解値を採用する際は、源の実値・記載式・計算定義を再確認する必要があります。
電子相互作用は液体の凝集エネルギー密度やδD／δP／δHの正解ではありません。
QM／MD由来の配置を持つことは、各行のHSP測定温度や材料適用を確定する証拠にもなりません。

1系列では系列を独立に分けた補助学習を成立させられないため、モデルを学習していません。
14,651配置を14,651化合物やHSP教師行として数えません。

## HB300SPX×10

[著者のNCIAtlas](https://github.com/Honza-R/NCIAtlas/tree/1816bfc72609d7deb1d4f93ab9e27eb13bb44bec)の
revision `1816bfc72609d7deb1d4f93ab9e27eb13bb44bec`を固定しました。
データREADMEは[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)を宣言します。
ZIP 2,116,482 bytesと定義YAML 1,812,689 bytesを取得し、両方のGit blob SHA-1とサイズが
固定treeの値と一致しました。ZIPのSHA-256は
`cfa420253be63395ef3548de9b389af15bc3a03feb185a8a22e942fef085d120`、YAMLは
`0666b5d609eb9318df43652ba0a1c0d8a1d29de4775565def976f63eef20ac32`です。

源定義はcounterpoise補正付きのcomposite CCSD(T)/CBS相互作用参照です。
最短距離点と平衡点は高い計算レベル、他の距離点は低い計算レベルからのrescalingを含みます。
それを個別の最高レベル計算と同一条件とは扱いません。
源XYZのbenchmarkとYAMLはkcal/molを明示します。
追加のSAPT・DFT・SQM表をHSP成分の教師へ対応させません。

全3,000配置・300距離系列で、源headerの両モノマーのatom selectionが重ならず全原子を覆うこと、
形式電荷の和、距離scaling、group、benchmark値が固定YAMLと一致することを確認しました。
全座標が有限です。YAMLのRuby object tagは文字列の構造として読むだけで、objectを生成したり
遠隔コードを実行したりしません。

この資産にはモノマーの源SMILESがありません。原atom selectionから分けた座標について、
RDKitの2種類のconnectivity計算が一致し、10点すべてでmonomer graphが変わらないことを
確認する、**暫定的な構造点検**を行いました。明示されたsource chargeを保持し、
未確認の電荷・原子価をneutralizeしたり別構造へ修正したりしません。
座標angstromは現時点ではXYZ形式の慣例による暫定解釈で、この資産自身の明示単位の証拠を
追加確認する必要があります。推定graphと慣例だけでは学習用の源同一性・単位を資格確認できません。

| 暫定構造監査 | 件数 |
| --- | ---: |
| 配置／距離系列 | 3,000／300 |
| 推定graph／推定モノマー系列 | 50／6 |
| 2手法と全距離点が一致するが予約と衝突する系列 | 283 |
| 原子価・未確認電荷などで判定を完了できない系列 | 17 |
| 予約外の暫定候補配置／pair／モノマー／系列 | 0／0／0／0 |
| 資格確認済みの学習候補配置／pair／モノマー／系列 | 0／0／0／0 |

17系列に属する170配置を、fallback、途中で成功したモノマー、net chargeだけの中性判定で
採用しません。283系列の暫定graphが予約に衝突する結果も、正式な源SMILESの確認とは区別します。
50個のgraphには、一方のモノマーだけで構造推定が終了した配置のgraphも含みます。
このinventoryを50個の資格確認済み学習分子とは数えません。
源SMILESと単位が未確認の系列は、たとえ推定graphが予約外でも学習へ入りません。

参照値を使う範囲を固定し、補助学習・HSP評価・設定選択を混同しません。
