# 非負応答を学習するkernel回帰

2026-10-12、757行の公開参照値で学習し、固定した1,013化合物・68系列で比較しました。
3成分の点MSEがHSPiT比較値以下という条件を保持したまま、評価1,013行と学習757行の
合計1,770行で負値・数値拒否を0件にできました。旧主方式と外部資産は変更していません。

これは既に探索した公開参照集団での比較です。実測／推定の系譜、温度と状態が不明な値を
`published_reference`として扱っています。独立実測、高分子・活性剤のHSP3成分、
校正済み不確実性の検証は未完了です。

## 固定した評価の結果

MSEの単位はMPa、MAE／RMSEはMPa^0.5です。小さいほど参照値との差が小さくなります。

| 方式 | δD MSE | δP MSE | δH MSE | 負値・拒否 |
| --- | ---: | ---: | ---: | --- |
| 保存済みHSPiT比較値 | 1.785945 | 16.837093 | 13.721079 | 元の比較規約を保持 |
| 旧QM9転移主方式 | 1.472484 | 11.133871 | 7.219472 | δPに負値6件 |
| 学習したsoftplus応答 v2 | 1.483965 | 11.183347 | 7.157551 | 負値0、拒否0 |

δD・δPは旧主方式より僅かに悪化し、δHは僅かに改善しました。
「全成分の精度が向上した」とは説明しません。成分別のMAE、RMSE、R²は次のとおりです。

| 成分 | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| δD | 0.930882 | 1.218181 | 0.507796 |
| δP | 2.380586 | 3.344151 | 0.381266 |
| δH | 1.951516 | 2.675360 | 0.702165 |

通常のHansen距離の重み`4 e_D² + e_P² + e_H²`で誤差をまとめると、
そのRMSは4.927145 MPa^0.5です。参照値に対する誤差であり、未知材料の溶解球半径との
関係や境界付近の溶解性判断を検証した値ではありません。成分MSEの通過だけで
配合・溶媒選択に十分な精度があるとは判断しません。

学習だけから定義したOOD688行では、δD MSEが1.963434で、比較値1.810068を超えています。
δP／δHのOOD MSEは13.252494／8.208047、比較値は17.628545／15.119052です。
OODのδPを系列ごとに等重みで集計すると33.107572で、比較値29.006316を超えます。
行平均と系列平均は同じ性能指標ではありません。

68系列を丸ごと再標本化する10,000回の対応付きbootstrapでは、点MSE差
「新方式−HSPiT」の95%区間はδDで[-1.576750, 0.169945]、
δPで[-10.648377, -2.960031]、δHで[-26.597647, -2.319856]でした。
δDの上限は0を超え、全成分の統計的優位性は確認できません。
これは露出済み参照値に対する記述的な集計で、独立実測や個々の予測区間の校正とは異なります。

## 公開する配列API

`hansenkit.softplus_kernels.SoftplusKernelHead`は1つのγ／αだけを明示して学習します。
候補選択、SMILESの適用判定、データ読込み、Embeddingの生成は呼出側の責任です。
`training_blocks`と`query_blocks`は`chemical`105列、`embedding`768列、`physics`1列以上の
同じ列規約を持つdictです。教師`training_delta`は非負の3列で、物理特徴だけ欠損を許します。
事前に権利と系列隔離を確認した学習側の配列だけを渡します。

```python
import json
from hansenkit.softplus_kernels import SoftplusKernelHead

head = SoftplusKernelHead.fit(
    training_blocks,
    training_delta,
    gamma=1.0,
    alpha=0.1,
    provenance=reviewed_training_provenance,
)
values, valid, refusal_reasons = head.predict(query_blocks)
restored = SoftplusKernelHead.restore(json.loads(json.dumps(head.state())))
```

出典宣言は`label_kind`、`training_allowed=True`、`source`、`permission_evidence`、
`approved_by`、`audit_basis`、`use_scope="scientific_private_noncommercial"`、
`public_redistribution=False`を要求します。評価専用の宣言や混在したラベル種類は拒否します。
この宣言は許諾の証明ではありません。自作の合成配列でも、`synthetic`と明示します。
復元では数値ランタイム、学習kernelと固有基底、前処理、出典・適用資格と収束証明を検査します。
stateのdigestは改変検出用であり、真正性・許諾・精度を保証しません。
教師をstateへ保存しないため、元の教師を使った損失の再計算は復元時に行いません。
保存先はignoredのローカル領域です。元の学習器の数値失敗は`NumericalRefusal`で
diagnosticsを保持して返し、予測時の非有限応答はmaskと理由で区別します。

## 応答を切り上げずに学習する

既存の`mixed_physics`を保持しました。標準化した化学105特徴の線形kernelに重み0.4、
固定MoLFormerの全768次元のRBFに0.4、既存物理特徴のRBFに0.2を与えます。
物理特徴24列だけの方式と、現行HSP系列を避けて学習したQM9推定6列を加えた方式を比較します。
PCA8の互換情報は学習内で計算して保存しますが、このkernelの計算には使いません。
エンコーダの重みは固定したままです。

各学習分割でだけGram行列を作り、固有分解から`F = V sqrt(λ)`を求めます。
queryには`K_query V / sqrt(λ)`を使います。θと切片bの符号を制限せず、応答を
`δ_hat = (1 MPa^0.5) logaddexp(0, F θ + b)`として学習します。
損失は元のδについての二乗誤差和の半分と`α ||θ||² / 2`です。
切片を正則化せず、ゼロの教師値も保持します。教師値の対数・逆変換や予測値の切上げは行いません。
浮動小数点のunderflowで0になる応答は保持し、非有限のlatentや応答は拒否します。

13候補は学習平均の対照と、物理特徴の2種類×γ0.1／1×α10／1／0.1の12方式です。
外側5分割、内側5分割で系列平均MSEを成分ごとに比較します。
前処理、固有分解、初期化、QM9特徴の扱いと候補選択は各分割の学習側だけに閉じます。
最終選択はδD・δHがQM9付きγ1／α0.1、δPが既存物理特徴のγ1／α0.1でした。
外側の学習系列平均MSEは0.317243／2.600983／1.281181、拒否0件です。
この学習内指標を外部参照1,013行の点MSEとは混ぜません。

## 数値失敗も残す

v1は直接θ、bをL-BFGS-Bへ渡しました。元の座標でgradient最大絶対値≤1e-5という
条件を学習候補が通過せず、全成分で平均値対照だけを選びました。
v1の固定参照MSEは6.147750／19.124816／27.685005で、条件未達です。
失敗したモデルを「構造を学習した」と説明しません。

v2は損失・応答・候補・初期化を変えず、可逆な座標変換
`θ = w / sqrt(λ + α)`、`b = c / sqrt(n_train)`を使います。
初期値も同じ分割の直接δ Ridgeから変換します。
`ftol=0`、`gtol=1e-9`、最大iteration3000／function10000／line-search40／memory10を固定しました。
元の座標のgradient条件1e-5、native success=true／status=0、目的関数・Jacobianの一致、
初期損失を超えない条件は保持しています。失敗時に閾値を緩めたり再試行したりしません。

独立した757×746の人工試験では、元のgradientが1e-5以内でもnative status=2になる例がありました。
この候補は不適格のまま残しました。実学習でも、外側5回の選択内で[1,1,0,2,0]件、
最終選択内で1件の数値失敗を保存し、選択に使いませんでした。
最終的に選ばれた2種類のheadはrank746、native status=0で、元のgradient最大絶対値は
7.0121e-7と2.5958e-6でした。局所的な数値条件であり、大域最適解や物理精度の証明ではありません。

## 独立照合と資産の境界

v2の著者合成テスト39項目と、別実装の目的関数、座標変換のchain rule、
全13候補の5×5系列選択、分割外の変更、起動権限と失敗記録の検査を通過しました。
全モデルと全1,770行の予測を先に保存し、別コマンドで参照数値を評価しました。
その後、独立NumPy実装で全1,770行を再計算し、予測差0、mask・理由・構造・系列・OODが一致しました。
最終headの損失・初期値も一致し、独立gradientとの差は最大7.55e-15でした。
独立側は外部評価ラベル、エンコーダ実行、再学習、optimizerを使っていません。
外側全モデルは保存されていないため、そのモデルを再学習して照合したとは説明しません。

公開APIへ移した後も、同じ2種類のheadをJSONで保存復元し、元の1,770予測・mask・理由を
完全一致で再現しました。この移植検査では教師配列、評価参照値、再学習、エンコーダとMDを
使っていません。53個の新しい著者テスト、全607テスト、Ruff、通常の合成CLIデモと
配布パッケージのビルドが通過しています。実測データの性能検査とは区別します。

## 実用化へ残る確認

非負性と参照MSEの両立は確認できました。独立した測定系譜と条件、系列を分離した未知材料、
OODのδD、予測区間の校正は未解決です。通常CLIは合成PoCの契約を保持します。
高分子、EO/PO活性剤、イオン、混合物に数値を返す資格へ広げません。
公開の配列APIでも、前処理済み入力に数値を返せることは化学的な適用判定の代わりになりません。

高分子は繰返し単位だけでなく、Mn／分布、末端、立体配置、温度・濃度と測定方法を揃えた
材料評価が必要です。活性剤はCMC、曇点、溶解・膨潤とHSPを別の物性として扱います。
LJ／CoulombのMD2項だけからδP／δHを分離しません。
次はこの非負応答を固定したまま、独立資料の資格確認、量子補助学習の拡張と
条件を揃えた物理観測の検証を進めます。露出済み参照の個別失敗を使う設定変更は行いません。
