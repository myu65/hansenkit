# 公開HSP学習データの追加調査

2026-10-11に、1,000化合物での比較に向けて新しい一次資料を調べました。
この調査で学習へ追加したHSP正解は0件です。候補の取得・構造照合と、
測定ラベルとしての採用を区別します。既存の18件は測定系譜が未確定の
`published_reference`で、独立実測の学習件数へ昇格させません。

ACS Omegaの薬物試験は室温で溶媒を段階的に加え、追加の間隔が1分です。
これは溶解試験に由来する操作上の球の中心で、平衡凝集物性の直接測定とは区別します。
数値の温度、試料の相・純度、不確実性を推測で補いません。
HSPiPによる球のフィッティングは著者の測定結果の解釈であり、構造推算値とは
区別できますが、ソフト名や球のFit値だけでは独立した物理精度を証明できません。
記事本体の取得XMLと11ページの付属PDFでは、HSPの単位の明示を確認できませんでした。
通常の単位や数値の大きさだけで確定せず、著者の明示を求める確認事項として保持します。
付属物は公式Europe PMC APIから取得し、ZIPのSHA-256は
`21a23950ffc1ae55f75a0499249f2bf88ba8ba176803b5b9647b49d181a2edbd`、
PDFは`5312291541679d9f2344711e8f736879ca1d721e9a93eab8dea483d21d1784e9`です。

## 構造予約とローカル記録

既存の予約を再構成して、1,266識別子・132骨格・2,798別名を保持しました。
予約ファイルのSHA-256は
`41e4bc755b3ad79e1b4ab50765c380aeed4ef6799709692c0c6bd7b5b5c13c82`です。
小さい集合へ置き換えず、旧骨格と完全な範囲内の互変異性体のつながりも残します。
resveratrolは系列予約に重なったため、今回の学習候補から除外しました。
未予約の構造にも、数値の採用や学習の許可を自動付与しません。

原資料、チェックサム、取得失敗、名前・識別子の照合結果は無視対象の
`local/source-renewal-v1/`に保存しました。外部コードやpickleは実行していません。
大容量のモデルZIPも取得せず、HSPiT Excelと参照CSVは評価専用のままです。
ローカル研究の許可を仮定する場合も`audit_basis="operator_assumption"`を記録し、
記事・原表・上流データ・公開重みの再配布許可を別々に確認します。

## 採用後の実験

候補の条件が揃ったら、実験由来の球の中心を独立した出典・測定種別で保存します。
未知の系譜を持つ参照値と混ぜた単一の「実測件数」は報告しません。
元の18件との系列重複も調べ、モデル・前処理・正則化の選択は学習系列内だけで行います。
Excel評価の値を、追加候補の採否、特徴、補助学習、調整や校正に使用しません。

採用できる件数が少ない間は、同じA/B/Cと学習内選択で増分を比較します。
1,000化合物の公開参照評価は既に見た評価であり、新しい独立実測テストとは呼びません。
実用精度の主張には、構造・測定条件・権利を揃えた新しい学習集団と独立評価集団が必要です。
今回の取得件数や候補数だけで、その目標を達成したとは扱いません。

この出典調査とは別に、ユーザーの追加学習指示と限定した部分集合レビューに基づき、
KouTerの33行・32構造を`published_reference`として使う
[50構造のローカル学習](reference-data-expansion.md)を実行しました。
元の取得禁止フラグや、独立実測の追加0件という分類は変更していません。
