# 現在のExcel予約によるHSP3成分の少数参照値学習

11件・10系列の公開参照値で学習し、別の1,013構造・68系列でA/B/Cと
QM9特徴追加を比較しました。全3成分の非劣性基準を満たした方式はありません。
学習の物性はδD・δP・δHですが、実測系譜・温度・材料状態が未確認なので
`published_reference` の研究実験です。独立実測の精度証明とは扱いません。
通常のHSP予測や、高分子・イオン・混合物・長鎖EO/POへの適用範囲も広げません。

## 予約と入力

[現在の系列規則](tautomer-isolation.md)に加え、過去のExcel予約を維持しました。
現在の全行判定だけの947構造・110骨格・2,115別名に、旧予約を併用すると
970構造・111骨格・2,162別名になります。最初の照合でこの違いを検出し、
学習前に修正しました。残る学習候補は、両条件とも11件・10系列です。
未定義の材料や不正な識別子は推測して埋めず、独立した分子の正解と数えません。

学習群とテスト群の同一性・骨格・保守的な位相・完全な互変異性体の別名の重なりは0。
補助学習用の全HSP予約1,266構造・132骨格・2,798別名は維持しています。
旧Excel予約もすべてこの集合に含まれることを確認しました。
Excelの数値、係数表、GC比較値、派生ラベルは、学習・特徴・標準化に使いません。

参照CSVはHSP-predictionsの版 `93f494824bca592d24f777db1dc6f975149e0aff`、
SHA-256は `8ec0f0a6012a339ea61778ad236be9d08080a3ed90f7b9d3f33b565d7f9d0ae3`。
以前に検討した1,030構造を固定した集団です。新しい盲検テストではありません。
元CSVと既存比較ファイルの構造順・先頭レコードの参照値を全件照合しました。
評価の13構造には、同じ正規化構造で異なる参照値が複数あります。学習の11構造にはありません。
1,013件の元の評価を保持し、数値が一意な1,000件だけの事後診断と、参照値の選択による
成分別MAEの範囲を別のローカルレポートへ保存しました。元のテストを置き換えず、
値の一意性を測定系譜・立体・条件の確定とも扱いません。
正解が化学構造から計算された値を含む可能性、同一性・立体・測定条件の不確かさを保持します。
ユーザーの監査通過の仮定による、正確な学習部分集合だけのローカル利用です。

単一の有機分子、明示した元素、512重原子・8,192文字以内を研究用に分類しました。
ニトロ基・硝酸エステルは、共有結合したN+/O−の明示的な部分構造だけを認識します。
構造や電荷は書き換えません。正味電荷0だけでは塩・双性イオンを許可せず、
N-oxide・azide・isocyanideなど未確認の電荷表記6件を拒否します。
最初の計画は全形式電荷を拒否して978件でした。この計画は学習前に保存したまま置き、
化学的な分類を修正した別の計画で、中性共有結合の35件を加えて1,013件を評価しました。
この変更にテスト物性や誤差は使っていません。

`hansenkit.charge.charge_classification` は構造の分類だけです。
既定のHSP適用判定は別に行い、分類しただけで数値を出しません。
独自官能基のカバレッジが1未満の評価構造は94件で、未割当比率を特徴に記録しました。
HSP基団係数を補完したり、カバレッジ1を主張したりはしません。

## 固定した学習と結果

Aは既存の105化学特徴、Bは確認済み固定MoLFormerの768次元。
Cは4分割で系列を分けて作ったAの残差をEmbeddingで補正します。
A＋QM9は、105特徴に固定量子物性ヘッドの6推定値を加えます。
QM9ヘッドは現在の全HSP予約を避けた61,622分子で学習したものです。
この件数を、HSPの学習正解11件に足して数えません。
量子特徴も実測値ではなく、特に絶対エネルギーの精度には限界があります。
MoLFormer自体は再学習せず、構造の事前学習集団との重複は未知です。

全方式でRidge alpha 100、標準化は各学習群だけから求めます。
テスト指標でパラメータ・方式・係数・除外対象を選び直していません。
予測を保存してハッシュを固定してからテスト参照値とGC比較値を読みました。
非負への切り上げは行わず、生の研究予測と負値の件数を残します。

単位はMPa^0.5。すべて同じ1,013構造の参照評価です。

| 方式 | δD MAE / RMSE / R² | δP MAE / RMSE / R² | δH MAE / RMSE / R² |
| --- | --- | --- | --- |
| A 化学特徴 | 1.435 / 1.782 / -0.053 | 2.730 / 3.604 / 0.282 | 3.295 / 4.654 / 0.099 |
| B 固定MoLFormer | 1.356 / 1.640 / 0.107 | 2.971 / 4.019 / 0.106 | 3.688 / 5.108 / -0.086 |
| C 残差ハイブリッド | 1.344 / 1.713 / 0.026 | 2.717 / 3.506 / 0.320 | 3.268 / 4.589 / 0.124 |
| A＋QM9推定特徴 | 1.434 / 1.777 / -0.047 | 2.589 / 3.426 / 0.351 | 3.330 / 4.694 / 0.083 |
| 学習群だけの定数 | 1.638 / 1.875 / -0.167 | 3.223 / 4.369 / -0.056 | 3.678 / 5.158 / -0.107 |
| 保存済みHSPiT比較値 | 0.979 / 1.336 / 0.408 | 2.818 / 4.103 / 0.068 | 2.411 / 3.704 / 0.429 |

事前基準は、各成分のMAE比が既存比較法の1.10以下、かつ系列を再標本化した
MAE差の片側95%上限が0.30以下。68系列を2,000回、固定seedで再標本化しました。
CとA＋QM9はδPだけが通過し、全方式でδD・δHは未通過でした。
CのδP上限は0.156、A＋QM9は0.156です。全3成分の非劣性を主張しません。
この数値基準を通過しても、未確定の測定系譜が独立実測になるわけではありません。

学習特徴の最小・最大の範囲外は969件、範囲内は44件です。
分布の狭い11件からの外挿で、範囲内だけの結果に評価対象を絞って合格にしません。
δP/δHの負値はAが2/2件、Bが0/0件、Cが11/3件、A＋QM9が1/2件。
負値を物理値として採用しません。独立した校正群がなく、校正済み予測区間もありません。

## 保存物の検証と次の実験

別プロセスで4方式の保存ヘッドを読み直し、全予測・3成分指標・OOD・負値件数・
系列平均・ブートストラップを照合しました。標準化と回帰を別のsklearn呼出しで
学習群だけから再計算し、Cの4分割残差も確認しました。
全1,030構造の特徴と、確認済みMoLFormerによるCPUの新しいEmbeddingも再計算しました。
ソースの整形は、計画時の写しと構文木が等しいことを確認しています。

CPUと保存済みGPUのEmbeddingは、791,040要素中1要素が初回の絶対許容差1e−4を
超えました。最大差1.08×10⁻⁴で、初回検証の失敗を保存しました。
許容差を変えて一致と扱わず、CPUの特徴で固定ヘッドとブートストラップを再評価し、
元の非劣性基準の判定が変わらないことを確認しました。元のモデル・予測は変更していません。
CPUでの固定ヘッドの最大予測変化は2.35×10⁻⁵ MPa^0.5、成分MAEの最大変化は1.10×10⁻⁷でした。

[Xylose acetalsの一次論文](https://doi.org/10.1002/cssc.202401877)も取得しました。
Kamlet–Taftの測定値と、HSPiP 5.3.02/Y-MBのHSP推算値を区別し、後者を実測の学習正解に
加えていません。[既存脂質資料のライセンス表記の不一致](reference-gc.md)も追記しました。

次は、学習群に欠ける分散・水素結合の構造群について、既存Excelと独立した
測定系譜・温度・材料仕様を持つδD/δP/δH資料を確保します。
このテストを見て同じ参照集団へ再調整する実験は、探索用と明示し、独立した新しい評価群を用意します。
1万行以上の補助学習とEmbeddingだけで、11件のHSP正解を補えるという証拠は得られていません。
1,000化合物の実測非劣性、高分子・長鎖界面活性剤の物理HSPバックエンドは未達です。
