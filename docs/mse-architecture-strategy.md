# 少数のHSP参照値でMSEを下げるための方式調査

2026-10-11に一次論文・公式API資料と既存実験を調べた。優先するのは、
特徴群ごとの加算カーネルと、成分ごとの学習系列内選択である。
既存の固定MoLFormer表現を使い、遠隔コード、追加重み、エンコーダ更新は必要としない。
この文書は候補と検証条件の調査記録であり、新しい学習結果ではない。
実際に実行する候補・対象・ハッシュは、別のローカル固定計画を正とする。

## 目標と比較対象

既存の比較時点のHSP学習集団は51参照行・50構造・40保守的系列、評価集団は1,013構造・68系列である。
測定系譜が未確定なので、ラベルは`published_reference`のままとする。
独立実測を追加しなくても、この参照集団へのMSEは計算・改善できる。
その改善から、実測HSP精度、温度依存、高分子やイオン性分子への適用を認定しない。
1,013構造は既に複数回評価されているため、追加実験を新しい盲検とは呼ばない。

今回の目標は、全1,013構造でδD・δP・δHそれぞれのMSEを保存済みHSPiT比較値以下にすることである。
MSEの単位はMPa、MAEとRMSEの単位はMPa^0.5である。
従来のMAE比1.10・MAE差の片側上限0.30という非劣性条件とは別に報告する。
従来の閾値を二乗したり、都合のよい成分平均へ置き換えたりしない。
比較値は評価にだけ使い、学習、特徴構築、校正、設定選択には使わない。

設定選択には、各系列内で二乗誤差を平均し、さらに系列間で平均する
成分別の系列マクロMSEを使う。評価の全行MSEも必ず併記する。
系列を等重みにする選択は、行を等重みにする最終目標と一致しない場合がある。
同一構造の異なる参照行は保持し、分割内に置く。計算コンフォマーや繰返し測定を
新しい独立HSP化合物数として数えない。

## 一次資料から得た判断

| 調査対象 | 確認した内容 | 今回への判断 |
| --- | --- | --- |
| 少数分子のGP | [Moss・Griffiths, FlowMO](https://arxiv.org/abs/2010.01118v2)は少数分子3データセットでGPと深層学習を比較している | 小さなカーネル回帰を比較する根拠になる。HSPや今回のOODに同じ精度・区間被覆を保証する論文ではない |
| GPとカーネルRidge | [scikit-learnの比較](https://scikit-learn.org/stable/auto_examples/gaussian_process/plot_compare_gpr_krr.html)と[GPの仕様](https://scikit-learn.org/stable/modules/gaussian_process.html)を確認した | 同じ固定カーネル・対角正則化・平均処理で得られる予測平均を、別の新方式として二重に数えない。GP分散は校正済みHSP不確実性とは扱わない |
| MoLFormer | [Rossほか, 2022](https://www.nature.com/articles/s42256-022-00580-7)は構造表現と物性予測・構造類似性を調べている | 既にレビュー済みの固定768特徴を再利用できる。論文の他タスク・別チェックポイントの結果を50構造のHSPへ移し替えない |
| Tanimotoカーネル | [Trippほか, 2023](https://arxiv.org/abs/2306.14809v2)は分子フィンガープリントの正定値カーネルと近似を扱う | 自前Morgan特徴による将来の対照候補。51行なら厳密Gram行列で十分で、ランダム近似や新パッケージは不要 |
| スタッキング | [Wolpert, 1992](https://www.sciencedirect.com/science/article/pii/S0893608005800231)は部分学習した予測を第二段の入力に使う。公式[StackingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingRegressor.html)も交差検証予測を使う | ベースの学習内予測で重みを決めない。40系列では追加段の選択分散が大きく、まず固定加算カーネルと成分別選択を実行する |
| Few-shotの関係学習 | [Wangほか, PAR, NeurIPS 2021](https://proceedings.neurips.cc/paper/2021/file/91bc333f6967019ac47b49ca0f2fa757-Paper.pdf)は物性依存の表現・分子間関係をメタ学習する | 主な実験は活性分類。3つのHSP成分だけで同じメタ学習条件を満たしたとは扱わない。補助タスク・構造重複・権利を別に資格確認してから検討する |
| コンフォマー | [Wangほか, ETKDG拡張, 2020](https://doi.org/10.1021/acs.jcim.0c00025)は小環・大環の構造探索を改善する | 3体から固定数の追加探索へ進む候補はある。気相に近い分子内幾何の改善は、液体の相互作用・凝集エネルギー・HSPの証明ではない |
| 選択そのものの過学習 | [Cawley・Talbot, 2010](https://jmlr.org/papers/v11/cawley10a.html)は選択基準の分散と評価の選択バイアスを示す | 無制限の候補探索より有限計画、系列ごとの入れ子検証、選択器自体の外側評価を優先する |

上記は候補を選ぶ理由であり、今回の精度改善の観測結果ではない。
他論文のモデル・重み・コード・係数を取得または実行していない。

## 既存方式から変える点

既存のRBFは、105化学特徴と8つの学習群PCA座標を結合し、一つの距離で比較する。
各列を標準化しても、距離への寄与は列数や冗長性に左右される。
特徴の追加が3成分を一様に改善しなかった[比較](physics-feature-comparison.md)に対し、
次は特徴群ごとのカーネルを作って加算し、群の寄与を明示する。
全768座標を使う候補とPCA8候補を分け、PCAで失う信号と高次元距離の不利を検証する。
全768座標に独立した長さ尺度を学習するARDは、50構造に対して設定数が大きいため初回では使わない。

入力群を次のように定義する。

| 記号 | 入力 |
| --- | --- |
| C | 既存105化学特徴。官能基、元素、サイズで規格化した特徴など |
| E | 既存の監査済み・固定MoLFormerの768座標、またはその分割の学習群だけで得たPCA8 |
| P | 既存の水素結合サイト・厳密なGasteiger電荷、QM9補助推定、422行で再学習したAbraham補助推定、3体の資格確認済み幾何特徴 |

Abrahamの422行とQM9の61,622行は、それぞれ参照記述子と量子物性の補助件数である。
今回の全HSP系列との重複がないことを再確認し、HSP学習件数へ足さない。
負の補助推定値を絶対値や0へ変えない。資格を満たさない派生比率はNaNと理由を保持する。
欠損補完と欠損マスク、全欠損列の除去は、各分割の学習群だけで求める。

各群の線形カーネルは標準化した座標の内積、RBFはその群の次元数で割った距離を使う。
各Gram行列は、その分割の学習対角の平均で規格化する。
評価側の対角・列分布を規格化に使わない。ゼロ対角平均の群は学習群内の情報がない群として記録し、
規格化の除数を評価群から補わない。この規格化は、HSPの物理式ではなく群間の統計的な重みを揃える操作である。

## 最初の有限候補

次の7テンプレートを候補とする。上付きlinとRBFは群ごとのカーネルを示す。
重みは事前に固定し、自由な多重カーネル最適化は行わない。

| テンプレート | カーネル | 仮説 |
| --- | --- | --- |
| 化学線形 | C lin | 既存の化学的寄与が外挿の基本になる |
| 表現線形 | E full lin | 768座標の信号をPCA切捨てなしで正則化する |
| 加算線形 | 0.5 C lin + 0.5 E full lin | 群ごとの規格化で線形融合を比較する |
| PCA加算RBF | 0.5 C RBF + 0.5 E PCA8 RBF | 従来の結合距離から特徴群加算へ変える |
| 全表現加算RBF | 0.5 C RBF + 0.5 E full RBF | PCAで失う信号があるかを調べる |
| 線形寄与と非線形補正 | 0.4 C lin + 0.4 E full RBF + 0.2 P RBF | 一つの閉形式回帰で化学の線形寄与と補助特徴の非線形寄与を表す |
| 化学・物理加算RBF | 0.8 C RBF + 0.2 P RBF | 表現と独立に物理補助群の寄与を確認する |

正則化alphaは10、1、0.1。RBFのgamma係数は0.1、1、10とし、群の次元数で割る。
全線形の3テンプレートにgammaの重複候補を作らない。
合計は45カーネル設定で、学習群の平均を返す定数候補を先頭に置く。
必要なら既存の正の通常ExtraTreesの4固定設定も同じ選択器に入れる。
二乗回帰や未収束MLPの予算を、既存評価の結果に合わせて変更して再試行しない。
この候補数は勧告であり、実行前の計画で最終確定する。

別の出典監査で、予約系列外の追加参照値を準備している。
公式構造照合、出典・重複・別名・権利条件の確認を通った行だけを追加する。
測定系譜が不明な表を、構造照合の成功だけで独立実測と呼ばない。
追加集団が約750構造になれば、最初は以下の4テンプレートへ候補を絞る。
旧50構造の評価結果で成分を振り分ける代わりに、拡張後の学習系列内で設定と成分を選ぶ。

| 拡張時のテンプレート | カーネル |
| --- | --- |
| 化学線形 | C lin |
| 加算線形 | 0.5 C lin + 0.5 E full lin |
| PCA加算RBF | 0.5 C RBF + 0.5 E PCA8 RBF |
| 線形寄与と非線形補正 | 0.4 C lin + 0.4 E full RBF + 0.2 P RBF |

RBFのgamma係数を0.1、1に固定し、alphaの3水準を組み合わせれば18設定である。
定数と既存の4つの通常正の木設定を含めても計23候補となる。
実行前にalphaの絶対水準か学習行数に比例する規則を明記し、途中で置き換えない。
補助モデルは拡張した全HSP系列を再予約してから監査・必要な再学習を行い、
以前の50構造への分割監査だけで拡張集団が隔離済みとは扱わない。

成分jの学習平均をm_jとして、閉形式の予測は次を使える。

```text
dual_j = solve(K_train + alpha I, y_train_j - m_j)
prediction_j = m_j + K_query_train @ dual_j
```

学習特徴、群ごとの標準化・補完、PCA、カーネル規格化、alpha、dualと平均をJSONへ保存できる。
学習特徴を含むJSONはローカル限定で、公開重みとして配布しない。
線形寄与＋RBF加算は別段の残差教師を作らないため、小さな実装で比較できる。
真の交差適合残差方式やスタッキングを追加する場合は、下記の別条件が必要である。

約750構造では、各学習分割・テンプレート・gammaごとの対称固有値分解を一度だけ実行し、
alphaの全水準と3成分で共用できる。化学の純線形候補は105次元の主問題でも解ける。
Gram行列は学習分割ごとに作り、外側を含む全行で作った標準化状態を使わない。
保存状態の予測と別実装の直接解の一致を検査する。
実装内部の計算再利用を、新しい方式や独立試行の増加として数えない。

固定計算予算を満たせない場合、別計画のNyström候補は128ランドマークなどの
有限近似として検討できる。ランドマークは各分割の学習構造だけから、
系列と正規化構造のハッシュで決定する。検証・評価構造からの中心選択、全入力での
クラスタリング、評価誤差に合わせたランク変更はしない。
ランドマーク、数値ランク判定、失敗・特異行列の扱いを固定して保存する。
最初の厳密計算と近似計算を混同しない。

## 選択と検証の順序

1. 既存の全予約・旧Murckoリンク・完全な有界互変異性体別名を維持して、入力と補助学習の系列を監査する。
   学習候補の追加は、原表の出典・単位・ラベル種別・利用許可・構造照合を別に確定する。
2. 候補集合、乱数種、系列分割、MSEの定義、失敗時の扱い、同点規則、計算予算を固定する。
   群の構成・重み・成分の組合せを評価表から選ばない。
3. 外側5系列分割の各学習群内で、内側5系列分割により全候補を成分別に選ぶ。
   その外側学習群だけで設定選択と再学習を完了し、外側の系列を予測する。
   これが「成分選択器」の入れ子検証値である。
4. 固定した全学習行の系列検証に同じ選択器を適用し、最終3成分の候補を決める。
   一般的な方式の外側平均から最良方式を選び、その同じ最小値を無偏の選択器性能と名乗らない。
5. 固定した全学習・評価入力行の予測、最終成分選択、モデル状態、入れ子検証結果を保存してハッシュで固定する。
6. その後でのみ1,013構造の数値評価を開き、全行MSE、系列マクロMSE、MAE、RMSE、R²、
   OOD・範囲内、負の予測数、各成分の厳密なMSE達成判定を計算する。
   結果が良い部分だけに絞ったり、既存の13参照規約の衝突を消したりしない。
7. 独立したNumPy／scikit-learn実装でカーネル、全候補、各分割、選択、JSON再読込みと指標を照合する。
   数値再現は、参照ラベルを独立実測へ格上げするものではない。

同点は1e−12以内で定数、次に固定した候補順を優先する。
3成分すべての目標達成と、各成分の改善を分けて報告する。
68系列のブートストラップは比較差の感度分析として別に示せるが、
strict MSEの点推定条件を緩めたり、予測区間の校正と呼んだりしない。

スタッキングを将来追加するなら、各外側学習群の中でベースの交差適合予測を作る。
各交差適合ベースの設定選択も、そのベースの学習群内でやり直す。
全51行で決めた設定・残差・メタ重みを外側群へ流用しない。
メタ設定を選ぶ検証の中でもベースの交差適合を再構築する。
既存の評価で良かった木のδDとRBFのδP・δHを直接組み合わせることは、この検証の代わりにならない。

## 次の物理特徴と表現の候補

既存の完全原子型付けによるCrippen屈折率寄与と幾何体積から、
屈折率寄与／幾何体積を一つの追加仮説として事前定義できる。
同じ体積を使う質量／幾何体積、既存のα／幾何体積、μ²／幾何体積とも比較する。
幾何体積は純液体のモル体積ではなく、これらの比率は実測密度や凝集エネルギーの値ではない。
Crippen値をHSPiTの係数で変換しない。欠損・単位・元の符号を保持し、
サイズの相殺が役立つかを同じ入れ子系列検証で調べる。

密度を学習した補助モデルを使う場合は、既存の[NIST候補](thermoml-auxiliary-review.md)の
21構造・16系列という規模、T/P条件、未完の原表照合、全HSP系列への予約を再評価する。
蒸発熱と密度が同じ物質・状態で揃わない値を、見かけの凝集エネルギーへ結合しない。
追加の補助ラベルは独立HSP教師ではなく、外部評価のHSP値で補助モデルを校正しない。

コンフォマー数を増やすなら、例えば20体・固定乱数種・固定最適化予算を計算前に確定する。
全体の収束条件、失敗理由、元の完全な座標・エネルギー記録を保持する。
外部HSPの誤差が大きかった分子だけ再計算したり、良いHSP値を出すコンフォマーだけ選んだりしない。
分子内MMFFエネルギーから作るBoltzmann重みは、その近似の仮説であり液体中の人口ではない。
追加体数をHSP学習行や独立分子の増加として数えない。

MorganのTanimoto対照は[RDKitの公式生成API](https://rdkit.org/docs/source/rdkit.Chem.rdFingerprintGenerator.html)で
固定radius、bit数、立体の扱いを記録して作れる。標準化した負の座標にはTanimotoを適用しない。
この対照は、表現ライセンスの追加なしで局所構造類似性の寄与を確認する候補である。
適用外分子の数値出力を通常CLIへ追加する理由にはしない。

新しい注意機構、深いMLP、GNN、PAR型メタ学習を先に大きくするより、
今回の50構造で検証できる有限候補と、予約系列外の参照教師の追加を優先する。
既存MoLFormerには注意機構があるが、固定表現への回帰ヘッドに追加注意を付ければ
HSP精度が上がるという証拠は、現在のHSP実験にはない。

## 保存すべき来歴

新しいローカル計画とモデルに`audit_basis="operator_assumption"`、
`scope="local_scientific_private_noncommercial"`、`label_kind="published_reference"`、
非再配布、実測精度未資格確認、校正済み区間なしを保存する。
原表、Excel数値、補助推定配列、コンフォマー、学習済み状態はGitへ入れない。
ソフト、重み、RDKitの埋め込み数表、教師・補助データのライセンスは別に保持する。
固定MoLFormerのコード・重み・実行許可の範囲と、通常の高分子・混合物・イオン・EO/PO拒否は維持する。

調査後に757行へ拡張して実行した53候補の比較と数値結果は、
[直接電子物性とMSEの実験記録](mse-reference-experiment.md)に分けて報告する。
本資料で述べた50構造時点の仮説・未実装候補を、拡張後の結果と混在させない。
