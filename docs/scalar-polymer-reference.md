# 高分子の単一δ・CEDを別に学習する

追加の[密度全件照合と系列隔離後の再学習](polymer-density-isolation.md)で、
旧学習の1系列に新しい未適用構造のつながりを確認しました。
この文書の元の指標は再学習前の履歴です。現在の比較はリンク先を参照してください。

2026-10-13、予約系列を避けた高分子の公開参照値で二つの回帰を実装・学習しました。
単一δは別系列で訓練平均の基準を改善し、CEDは悪化しました。
対象はHansenの3成分ではありません。測定系譜・材料条件が不明な参照値との比較で、
高分子・活性剤の実用HSP推論は引き続き未認定です。

## 数値を読む前の分割

[PolyBench version2](https://doi.org/10.6084/m9.figshare.30917717.v2)の
単一δ316行、CED307行をローカルで取得し、配布元のファイルMD5を照合しました。
[原論文](https://doi.org/10.1021/polymscitech.6c00094)は複数の文献・データベースを集約しています。
行ごとの実測／計算の系譜、温度、Mn/Mw、末端、試料状態は未確認です。
教師種は`published_reference_auxiliary`で、実測HSPの件数へ加えません。

全623行・320原構造を保持し、従来のMurcko・互変異性体・保守的core・周期系列リンクと
同一資料の高分子名を、両タスクをまとめた69系列へ対応させました。
5,176予約との接続等で16系列を隔離し、候補は53系列・177行です。
原構造は特徴量の入力、系列キーは分割用に使います。

特徴量・数値ラベルを読む前に、seed20261013で訓練32・校正11・評価10系列へ固定しました。
一方のタスクの訓練系列が、他方の評価系列へ入ることはありません。
タスクごとの実際の行・系列数は次の通りです。

| タスク | 訓練行/系列 | 校正行/系列 | 評価行/系列 | 候補行 |
| --- | ---: | ---: | ---: | ---: |
| 単一δ | 62/31 | 17/11 | 15/10 | 94 |
| CED | 55/28 | 16/11 | 12/8 | 83 |

## 特徴量と固定した比較

原表の二端ポート付き繰返し単位をそのままRDKitへ入力します。ポートをcapしたり、
末端・分子量から鎖を推定したり、分割キーを構造入力へ置き換えたりしません。
19特徴は、12元素とその他の重原子比率、重原子数、芳香族・環原子比率、
重原子数あたりのHBD・HBA・TPSAです。最後の三つは原単位の構造代理量であり、
鎖全体や実測の水素結合強さを意味しません。

組成の原子カバレッジと、元のSMARTSによる官能基所属を分けて記録します。
ポート隣接酸素やSi等の未所属原子も残し、組成の100%所属を官能基の完全対応とみなしません。
官能基所属の監査結果は今回の回帰入力には加えていません。

候補は線形ridgeとRBF、それぞれα=0.1/1/10の固定6個です。RBFのγは1/19です。
系列を等重みにして、前処理は各訓練分割だけで計算し、応答はlog/expを使います。
正で有限なラベルを必要とし、epsilon、予測の切詰め、拒否行の除外はしません。
訓練系列内の5foldで原単位の系列平均MSEを比較し、各fold内で前処理と回帰を作り直します。
最終選択は単一δがridge α0.1、CEDがRBF α0.1でした。候補の数値拒否は0件です。

単一δの宣言単位は(J/cm³)¹⁄²、CEDはcal/cm³です。calの定義は不明のまま、
単位変換・相互変換・HSP3成分への分解を行いません。
モデル・全分割の予測・訓練平均基準を先に保存し、別の確認で保留ラベルを読みました。
「校正」分割も今回の比較では記述評価だけで、確率・区間・閾値の校正には使っていません。

次は評価分割の系列等重み指標です。RMSE/MAEは各タスクの原宣言単位です。
異なるタスクの数値同士を比較しません。

| タスク | 方式 | MAE | MSE | RMSE | R² |
| --- | --- | ---: | ---: | ---: | ---: |
| 単一δ | 訓練内で選択した回帰 | 3.196 | 14.227 | 3.772 | 0.352 |
| 単一δ | 訓練平均だけ | 3.774 | 22.577 | 4.751 | -0.029 |
| CED | 訓練内で選択した回帰 | 81.169 | 7708.147 | 87.796 | -12.650 |

行等重みでも単一δのRMSE3.424・R²0.421に対し、CEDはRMSE77.832・R²-7.158です。
校正分割の系列等重みRMSEは単一δ3.779対基準5.135、CED84.587対47.618でした。
CEDを保留結果を見て別モデルへ変更していません。

全19列の訓練範囲外という記述的OOD件数は両タスク・全分割で0件です。
それでもCEDの別系列の誤差は大きく、列ごとの範囲内であることは化学的適用や精度の資格になりません。
少数系列の点指標から有意な優越、独立実測の精度、未知の鎖長・末端への適用を主張しません。
全623行と隔離・官能基の未所属を保存し、元資料・学習済み重みは公開していません。

## 公開APIと検証

公開するのは独自MITの配列回帰・原単位特徴と自作テストです。資料・係数・重みや
データ読込みの許可を含みません。呼出側で正規化済み系列・評価予約・原資料の権利を確認し、
単位と教師種を明示してください。配列の入力だけでは、分割の独立性や材料の適用資格は得られません。
通常のHSP推論、外部ダウンロード、サービスは追加しません。

`scalar_reference`には、`ScalarReferenceHead`、`fit_group_selected_scalar_reference`、
`raw_repeat_unit_features`があります。末端を補わない構造監査は単独で使えます。
回帰へ渡す配列と系列・訓練行は、呼出側で資料の権利と分割を確認したものを用意します。

```python
from hansenkit.scalar_reference import (
    ScalarReferenceHead,
    fit_group_selected_scalar_reference,
    raw_repeat_unit_features,
)

features, audit = raw_repeat_unit_features("*CCO*")
head, selection = fit_group_selected_scalar_reference(
    approved_x,
    approved_scalar_y,
    families,
    training_indices=training_row_ids,
    provenance=reviewed_provenance,
)
restored = ScalarReferenceHead.restore(head.state())
reference_values = restored.predict(query_x)
range_diagnostics = restored.ood(query_x)
```

`reviewed_provenance`にはタスク・原宣言単位・教師種・私用非商用の範囲に加え、
原資料、同名系列台帳、予約台帳、固定分割、学習レビューのSHA-256を記録します。
権利の承認、学習・私有派生重みの許可は別に確認し、デフォルトHSP・物理資格・配布等の
フラグはfalseのまま保持します。これらの宣言や整合性digestは許諾の証明ではありません。
欠損・空白・浮動小数・boolの系列キー、整数と文字列の混在、単位・教師種の混在を拒否します。
設定選択では対象訓練行を先に選び、保留したlistやobject配列の値を変換しません。

ローカルの学習ランナー34、独立な入出力ゲート6、保留評価15の自作テストを確認しました。
公開APIの41自作テストも通過し、全pytest726件、Ruff check/format、合成CLIの学習・比較・
CSV出力、オフラインのsdist/wheelビルドを確認しました。
独立な4自作fixtureを通したNumPy・scalar再計算でも、全177件の予測は保存値と完全一致しました。
訓練だけの平均・尺度・mask・範囲と、両保留分割の行／系列指標も1e-11の数値照合基準に一致しました。
この基準は同じ資料の数値再現用であり、物理精度の許容値ではありません。
隔離等の446行は数値ラベルへ変換していません。独立実測からの再評価や再学習ではありません。
最初の学習では全19列の入力配列を別保存していなかったため、保存した原構造・官能基監査から
固定RDKitで177行を再計算しました。監査結果は一致しますが、元の学習入力配列のバイト同一性とは区別します。
